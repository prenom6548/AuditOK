# openKylin 3.0版本发行说明

OpenAtom openKylin（简称"openKylin"）3.0版本正式发布！

本版本基于Linux 7.0内核构建，以"AI原生"为核心设计理念，搭载全新UKUI 4.24桌面环境，带来从底层架构到桌面交互的全方位升级。

## 硬件兼容性共建

openKylin社区欢迎广大爱好者参与硬件兼容性测试共建！

如果您手头的设备可以正常安装和使用openKylin 3.0，欢迎在对应架构的硬件支持清单中提交PR，添加您的机型信息，包括：品牌机型、CPU型号、显卡、内存、存储、安装版本、测试结果及备注。您的每一次贡献都将帮助更多用户了解openKylin的硬件兼容情况。
