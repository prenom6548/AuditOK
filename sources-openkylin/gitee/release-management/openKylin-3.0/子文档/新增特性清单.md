# openKylin 3.0 新增特性清单

## 一、Linux 7.0 内核

openKylin 3.0 率先搭载 Linux 7.0 内核，为国内首个基于该内核的开源桌面操作系统。

主要特性包括：

- Intel Nova Lake + AMD Zen 6 新架构支持
- XFS 文件系统自修复能力
- EEVDF 调度器取代 CFS，任务调度算法优化
- Intel Shadow Stack 硬件级安全防护
- Atomic Writes 原子写技术，提升存储性能
- 深度适配 RISC-V RVA23 高性能规范，推动 RISC-V 从嵌入式向桌面、服务器及高性能计算领域延伸
- 180+ 核心基础库跨代升级

### WLCOM 显示框架

openKylin 3.0 搭载新一代基于 Wayland 显示协议开发的 WLCOM 合成器，相比传统 X11 具备图形渲染性能更高、显卡生态兼容性更佳、第三方依赖更少的优势。本版本在窗口管理、特效渲染、多屏支持等方面持续完善，拖拽贴边、窗口预览等交互体验更加成熟，已具备作为默认显示服务的能力。

### 后量子密码体系

openKylin 是国内最早系统性布局后量子密码的开源操作系统社区之一，在 3.0 版本中构建了从算法原语、密码套件到操作系统迁移的三层防线：

**1. 算法原语层 —— NIST 三大标准原生实现**

- kyber-package：ML-KEM-768（FIPS 203）密钥封装，基于 Module-LWE，守护 TLS 等通信密钥协商
- dilithium-package：ML-DSA-2（FIPS 204）数字签名，用于身份认证、代码签名、证书签发
- sphincs-package：SLH-DSA-128s（FIPS 205）哈希签名，仅依赖哈希函数，提供后量子签名"安全底线"，代码遵循 MISRA-C:2012 车规级规范

**2. 密码能力层 —— openHiTLS 全栈密码套件**

openHiTLS 由西安电子科技大学、山东大学、上海交通大学、华为等 13 家产学研机构共同发起，已引入 huanghe（3.0）分支作为系统级密码基础设施：

- 算法层全面支持 ML-KEM、ML-DSA、SLH-DSA 三大 NIST 标准，并覆盖 XMSS、Classic McEliece、FrodoKEM 等
- 协议层在 TLS 1.3 中原生集成后量子密钥交换，默认采用传统算法 + ML-KEM 的混合密钥协商策略，兼顾抗量子与兼容性
- PKI 证书层原生支持 XMSS、ML-DSA、SLH-DSA 后量子证书标准
- 同时支持 SM2/3/4/9 国密算法及隐私计算协议，200+ 功能模块按需裁剪，内存占用可降低 80% 以上

**3. 迁移协调层 —— PQCTransition SIG**

社区专门成立后量子密码迁移特别兴趣小组，统筹 PQC 算法在 openKylin 系统组件中的集成测试、兼容性验证和渐进式迁移规划，确保从传统密码到后量子密码的平滑过渡。

## 六、AI 原生智能

openKylin 3.0 在系统架构层面原生支持多元智能体流畅运行，打造操作系统级 AI 运行时环境。

- 集成 KylinBot 智能体，内置 AI 助手 5.0
- 集成 Kylin-CUA 桌面自动化工具
- 内置十多项系统技能，覆盖输入设备、显示控制、屏幕亮度、网络管理、外设管理、系统控制等
- AI 助手新增本地知识库功能，支持技能与通道配置
- 兼容 WorkBuddy、OpenClaw 等主流第三方智能体，支持接入微信、钉钉、飞书等即时通讯渠道
- 端侧与云端大模型灵活调度，可按需选择本地推理或云端服务
- 社区联合生态伙伴发起万亿 Token 计划，为开发者与用户提供 AI 算力资源

- 电源管理电量图标及关键电量提醒策略调整

## 八、系统工具 Rust 改造

openKylin 设立 RFL（Rust for Linux）SIG，从用户态系统工具起步，逐步推进 Rust 化改造，从编译期消除缓冲区溢出、use-after-free 等内存安全漏洞。3.0 版本首批完成三个工具的 Rust 重构：

- 新增 kylin-time 替代原 time 工具
- 新增 kylin-ki18n 替代原 ki18n 工具
- 新增 kylin-wget 替代原 wget 工具

每个组件须通过功能等价、性能不退化、安全审计、构建可复现、文档可维护五道门禁方可进入发行版，并在打包层面保留 C/C++ 原版以支持秒切回退。社区同时在 gitcode.com 维护 rust-for-linux 跟踪仓库（linux-7.0-next 分支），持续跟进上游内核 Rust 驱动与抽象层进展，为未来内核态 Rust 能力做储备。

## 九、磐石架构体验优化

磐石架构由不可变系统、KARE 兼容环境与开明包格式三大核心技术协同构成。3.0 版本进一步优化权限管理：

- 系统权限管理全面优化，默认赋予用户更自由的系统管理权限（如无需切换模式即可使用 apt 安装软件包）
- 降低日常权限操作门槛，提升桌面使用体验
- 保持不可变基座的安全性与稳定性

## 十、系统镜像瘦身

通过组件裁剪、依赖优化与压缩算法改进，openKylin 3.0 系统镜像体积从上一版本的 8G+ 缩减至 6G，下载安装更快，磁盘占用更少，同时功能完整性不受影响。

- 配套原生开发 SDK 与 AI SDK 全面升级，支持 3000+ 系统原生开发接口，覆盖 UI 组件、系统服务、硬件访问、AI 推理等开发场景
- 深度适配 UKUI 4.24 桌面环境、WLCOM 合成器及 KART AI 子系统
- KylinCode 集成开发环境提供一站式编码、调试与构建服务
