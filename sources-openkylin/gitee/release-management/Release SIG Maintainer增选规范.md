## Release SIG Maintainer增选规范
### 基本要求
1、签署CLA时间超过6个月，且社区贡献积分超过6000分；

2、持续参加Release SIG例会，最近6个月参加Release SIG相关会议50%以上。
### 提交申请材料
满足上述基本条件并有意加入Release SIG Maintainer行列的开发者，可以通过回复Release SIG周例会议题收集邮件来提交申请材料，申请材料模板参考如下：
```
一、基本信息：
    1、申请人：姓名、Gitee_ID或邮箱地址
    2、推荐人：姓名（备注：申请人需提前沟通，至少获得一位Maintainer的推荐）
二、贡献列举（版本release管理相关）：
    1、统筹把控各SIG组版本开发、集成、测试、发布进度，已按期发布0.7和0.7.5两个版本
    2、xxxxxx
```
### 投票表决
全体Release SIG Maintainers进行投票表决，投票分为赞同票、反对票和弃权票，可以会上直接表决或会后回复邮件表决。需要三分之二或以上Maintainers投赞同票时，申请才能通过。投票结果通过邮件列表公示。
