# 系统截图（kylin-screenshot）
调用麒麟系统自带 `kylin-screenshot` 命令行工具完成截图，支持全屏、窗口、选区三种截图模式，支持延迟截图、自定义图片保存路径，截图完成后返回图片存储位置给用户。
## 触发条件
用户表达以下任一意图时触发：
- "截图"、"截个图"、"帮我截一下屏幕"
- "截全屏"、"全屏截图"、"截取整个屏幕"
- "截取当前窗口"、"截一下这个窗口"
- "框选截图"、"选区截图"、"只截一部分画面"
- "延迟3秒截图"、"等5秒再截图"
- "截图保存到桌面"、"截图存到图片文件夹"
## 核心功能
1. **截图模式区分**
    - full：全屏截图，捕获整个显示器画面
    - screen：窗口截图，仅捕获当前活动窗口
    - gui：选区截图，手动拖拽框选指定区域
2. **延迟抓拍**：支持设置延迟秒数，等待指定时间后再执行截图，方便切换页面
3. **自定义存储**：可指定图片保存路径，未指定则自动存入系统默认截图目录
4. **输出标准化**：执行命令携带 --json 参数，返回结构化截图文件路径，方便AI反馈给用户
## 支持参数说明
- mode：截图模式，必填，可选 full / screen / gui
- delay：延迟秒数，非负整数，不传则立即截图
- save_path：图片保存路径，不传使用系统默认目录
- Newname: 保存图片文件
## 执行流程
### 第1步：解析用户意图提取参数
从用户对话中识别截图模式、延迟时长、保存路径、保存文件名称四类信息；
若用户未指定任何参数，默认执行**全屏即时截图**。
