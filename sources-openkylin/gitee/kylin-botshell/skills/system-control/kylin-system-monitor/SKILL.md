# 系统监视器（ukui-system-monitor）

调用封装脚本打开 UKUI 系统监视器，用于查看系统进程、资源占用等信息。**禁止直接运行 ukui-system-monitor 命令，所有操作必须通过 system-monitor.sh 脚本执行。**

## 触发条件

用户表达以下任一意图时触发：
- "打开系统监视器"、"打开进程管理器"、"打开任务管理器"
- "查看系统进程"、"查看资源占用"
- "打开系统监视器进程页面"

## 核心功能

| # | 功能 | 说明 |
|---|------|------|
| 1 | 打开系统监视器 | 打开系统监视器主界面（进程页面） |

## 支持参数说明

- **action**：必填，指定要执行的操作。可选值：
  - `open` — 打开系统监视器

## 执行流程

**重要规则：所有操作必须通过脚本执行，严禁直接调用 ukui-system-monitor 命令。**

**算力约束：本技能运行在本地算力受限环境，操作均为简单的 GUI 启动，无需深度思考或复杂推理，识别意图后直接执行即可，不要做多余的分析或拆解。**

### 第1步：解析用户意图确定 action

从用户对话中识别需要执行的操作，映射到 `open` action。

### 第2步：调用脚本执行

```bash
bash <skills_dir>/kylin-system-monitor/scripts/system-monitor.sh run open
```

不要直接运行 `ukui-system-monitor` 或任何其他参数组合，所有命令调用都通过脚本封装。

### 第3步：获取执行结果

脚本返回 JSON 格式的执行结果，包含 `success`、`exit_code` 和 `msg` 字段。根据结果向用户反馈：
- 成功：按「助手端显示」规范回复对应文案
- 失败：提示用户命令执行异常

## 最终回复规范

| 操作 | 回复文案 |
|------|----------|
| 打开系统监视器 | 指令已执行，为你跳转到目标页面。 |
