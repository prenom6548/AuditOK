# 财务制度模板

本目录包含常用的财务制度模板，可根据企业实际情况修改使用。

## 目录内容

1. **差旅费报销制度.md** - 差旅费报销标准和流程
2. **费用审批制度.md** - 各类费用审批权限
3. **发票管理制度.md** - 发票获取、开具、保管规定
4. **预算管理制度.md** - 预算编制、执行、考核

---

## 模板使用说明

### 如何使用模板

1. **下载模板**：复制对应模板内容
2. **根据企业情况修改**：调整金额标准、审批流程
3. **征求意见**：法务、财务、业务部门审核
4. **正式发布**：经管理层审批后执行
5. **培训宣贯**：组织相关人员学习

### 修改要点

| 项目 | 修改建议 |
|------|----------|
| 金额标准 | 根据企业规模和行业特点调整 |
| 审批流程 | 考虑管理幅度和效率平衡 |
| 适用范围 | 明确适用对象和例外情况 |
| 实施日期 | 设置合理的过渡期 |
