# 费用审批制度

**版本**：V1.0  
**生效日期**：2024年1月1日  
**适用范围**：公司全体部门

---

## 一、总则

### 1.1 目的
明确各类费用支出的审批权限，规范审批流程，提高工作效率。

### 1.2 费用分类
- **日常费用**：办公费、交通费、通讯费等
- **业务费用**：业务招待费、市场推广费等
- **管理费用**：人力成本、房租水电等
- **资本性支出**：设备采购、工程投资等

---

## 二、审批权限

### 2.1 日常费用审批

| 金额范围 | 审批人 | 备注 |
|----------|--------|------|
| 1,000元以下 | 部门负责人 | 直接审批 |
| 1,000-5,000元 | 部门负责人 + 财务 | 财务复核 |
| 5,000-20,000元 | 部门负责人 + 分管副总 | 双签审批 |
| 20,000元以上 | 总经理 | 专项审批 |

### 2.2 业务招待费审批

| 金额范围 | 审批人 |
|----------|--------|
| 2,000元以下 | 部门负责人 |
| 2,000-5,000元 | 分管副总 |
| 5,000元以上 | 总经理 |

> **注意**：业务招待费需事先申请，事后报销须说明招待对象和目的。

### 2.3 采购审批

| 金额范围 | 审批人 | 流程 |
|----------|--------|------|
| 5,000元以下 | 部门负责人 | 口头通知采购 |
| 5,000-50,000元 | 部门负责人 + 采购部 | 询价对比 |
| 50,000-200,000元 | 分管副总 | 招标审批 |
| 200,000元以上 | 总经理 | 专项审批 |

### 2.4 资本性支出审批

| 金额范围 | 审批人 | 附件要求 |
|----------|--------|----------|
| 10万元以下 | 分管副总 | 项目申请 |
| 10-50万元 | 总经理 | 可行性报告 |
| 50万元以上 | 董事会 | 完整投资分析 |

---

## 三、审批流程

### 3.1 标准审批流程
```
申请人 → 部门负责人 → 财务审核 → 分管副总 → 总经理 → 出纳付款
```

### 3.2 紧急审批流程
紧急情况下，可先电话/微信审批，事后补办书面手续：
1. 发起人口头说明情况
2. 审批人电话/微信同意
3. 事后24小时内补办手续
4. 财务存档备查

---

## 四、超预算审批

### 4.1 预算内支出
按上述权限正常审批。

### 4.2 超预算支出
- **超预算10%以内**：部门负责人说明原因，财务总监审批
- **超预算10%-30%**：编制追加预算申请，总经理审批
- **超预算30%以上**：重新编制预算，董事会审批

---

## 五、审批原则

1. **合规性**：符合公司制度和国家法规
2. **必要性**：确为业务开展所需
3. **经济性**：性价比最优
4. **及时性**：不延误业务
5. **可追溯**：完整保留审批记录

---

## 六、责任追究

### 6.1 申请人责任
- 虚报费用、弄虚作假者，追回款项并处罚
- 未按流程审批的，自行承担损失

### 6.2 审批人责任
- 越权审批造成损失的，承担相应责任
- 审批失职导致公司损失的，追责处理

---

- 附件3：预算调整申请表
