# 发票管理制度

**版本**：V1.0  
**生效日期**：2024年1月1日  
**适用范围**：公司全体部门及子公司

---

## 一、总则

### 1.1 目的
规范发票的获取、开具、保管及管理，防范税务风险。

### 1.2 发票类型
- **增值税专用发票**：一般纳税人可抵扣
- **增值税普通发票**：不可抵扣，但可作为报销凭证
- **电子发票**：与纸质发票具有同等法律效力
- **定额发票**：适用于无法开具增值税发票的小额支出

---

## 二、发票获取规定

### 2.1 索取发票原则
- **必须取得**：所有对外支出必须向收款方索取发票
- **合法合规**：发票来源合法，内容真实
- **及时索取**：交易完成后及时取得发票

### 2.2 发票内容要求

| 必填项目 | 普通发票 | 专用发票 |
|----------|----------|----------|
| 购买方名称 | ✅ | ✅ |
| 纳税人识别号 | - | ✅ |
| 地址电话 | - | ✅ |
| 开户行账号 | - | ✅ |
| 商品服务名称 | ✅ | ✅ |
| 金额 | ✅ | ✅ |
| 税率 | - | ✅ |
| 税额 | - | ✅ |

### 2.3 发票抬头
- **抬头名称**：须与公司营业执照一致
- **示例**：`XXX有限公司`
- **注意**：不得简写、不得错误

---

## 三、发票开具规定

### 3.1 开票申请
- 填写《发票开具申请单》
- 提供完整开票信息
- 注明开票项目内容

### 3.2 开票时限
- **普通发票**：即时开具
- **专用发票**：3个工作日内开具
- **电子发票**：即时开具

### 3.3 作废红冲
- **当月作废**：直接作废
- **跨月红冲**：需开具红字发票
- **流程**：申请人说明原因 → 税务会计审核 → 开具红字发票

---

## 四、发票保管

### 4.1 保管责任
- **财务部**：负责发票购买、领用登记
- **各部门**：负责本部门发票的收集、传递
- **经办人**：负责发票的真实性、完整性

### 4.2 保管期限
- 发票存根联：保存5年
- 发票抵扣联：保存5年
- 电子发票：打印保存或电子存档

### 4.3 归档要求
- 按时间顺序整理
- 按月份装订成册
- 存放在干燥、安全处

---

## 五、发票丢失处理

### 5.1 丢失发票联次

| 丢失情况 | 处理方法 |
|----------|----------|
| 丢失发票联 | 取得对方记账联复印件，加盖发票专用章 |
| 丢失抵扣联 | 取得发票联复印件，单独认证 |
| 全部丢失 | 登报声明作废，向税务机关报告 |

### 5.2 处理流程
1. 立即报告财务部
2. 取得原发票复印件或证明
3. 填写《发票丢失说明》
4. 财务部向税务机关报备
5. 相关人员书面检讨

---

## 六、发票合规检查

### 6.1 日常检查
- 报销时审核发票真伪
- 抽查发票内容完整性
- 检查发票与业务匹配性

### 6.2 不合规发票处理
- **假发票**：不予报销，追责处理
- **内容错误**：退回报销人换开
- **逾期未取得**：不予报销
- **虚开发票**：追究法律责任

---

## 七、违规处罚

| 违规行为 | 处罚措施 |
|----------|----------|
| 虚开发票 | 解除劳动合同，移送司法机关 |
| 购买假发票 | 解除劳动合同，税务处罚 |
| 丢失发票 | 书面检讨，扣除绩效 |
| 报销假发票 | 追回款项，行政处分 |

---
