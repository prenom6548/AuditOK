# 差旅费报销制度

**版本**：V1.0  
**生效日期**：2024年1月1日  
**适用范围**：公司全体员工

---

## 一、总则

### 1.1 目的
规范差旅费报销管理，控制差旅费用支出，确保业务开展需要。

### 1.2 适用范围
本制度适用于公司全体员工因公出差所发生的费用报销。

### 1.3 差旅费定义
差旅费是指员工因公到常驻地以外地区出差，所发生的城市间交通费、住宿费、伙食补助费和公杂费。

---

## 二、报销标准

### 2.1 交通费

| 出行方式 | 报销标准 | 说明 |
|----------|----------|------|
| 飞机 | 经济舱 | 须提前申请，优先选择打折机票 |
| 火车 | 二等座/硬卧 | 高铁优先 |
| 长途客车 | 实报实销 | 需提供车票 |
| 出租车/网约车 | 原则上不报销 | 特殊情况需部门负责人审批 |
| 市内交通 | 每人每天80元 | 含地铁、公交、打车 |

### 2.2 住宿费

| 职级 | 一线城市 | 二线城市 | 三线城市 |
|------|----------|----------|----------|
| 高管 | 800元/天 | 600元/天 | 500元/天 |
| 部门负责人 | 500元/天 | 400元/天 | 300元/天 |
| 普通员工 | 350元/天 | 280元/天 | 220元/天 |

> **说明**：
> - 出差天数按实际住宿天数计算
> - 特殊情况超出标准需事先审批

### 2.3 伙食补助费

| 地区 | 标准 |
|------|------|
| 一般地区 | 100元/天 |
| 西藏、青海、新疆 | 120元/天 |
| 北京、上海、广州、深圳 | 150元/天 |

### 2.4 公杂费
- 标准：50元/天
- 包含：通讯费、行李托运等

---

## 三、报销流程

### 3.1 出差申请
1. 出差前填写《出差申请表》
2. 提交部门负责人审批
3. 报财务部备案
4. 借款（如需要）

### 3.2 出差审批权限

| 出差天数 | 审批人 |
|----------|--------|
| 3天以内 | 部门负责人 |
| 3-7天 | 分管副总 |
| 7天以上 | 总经理 |

### 3.3 报销流程
```
出差归来 → 整理票据 → 填写报销单 → 部门负责人审批 → 财务审核 → 出纳付款
```

---

## 四、报销时限

1. **出差结束后5个工作日内**完成报销
2. 跨月报销须在**当月底前**提交
3. 逾期未报销的，财务部有权拒绝受理

---

## 五、注意事项

### 5.1 票据要求
- 必须提供正规发票
- 发票抬头须为公司全称
- 日期、金额、项目须清晰
- 发票内容与实际相符

### 5.2 不予报销项目
- 非因公产生的费用
- 参观景点门票
- 私人消费
- 礼品、娱乐费用
- 违停罚款

### 5.3 其他规定
- 多人出差，按实际人数报销
- 与外部人员同行，原则上不报销招待费
- 使用公司信用卡或借记卡支付优先
