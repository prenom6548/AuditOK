## 模块一：发票智能处理

**功能说明**：
- 支持多种发票类型：增值税普通发票、增值税专用发票、电子发票
- 智能识别发票关键字段：发票代码、发票号码、开票日期、金额、税额、价税合计
- 合规性检查：检查发票抬头是否正确、税号是否匹配、是否存在重复报销风险
- 按报销规则自动分组（差旅费、招待费、交通费、办公费等）
- 导出标准报销Excel表格

**触发词**：`/发票`

**使用示例**：
```
/发票 报销以下发票：
1. 2024年1月15日，北京出差住宿费，金额1580元，税额47.4元
2. 2024年1月16日，高铁票2张，共580元
3. 2024年1月16日，业务招待费，金额1200元
```

**输出格式**：
```
## 发票识别结果

| 序号 | 日期 | 发票类型 | 金额(元) | 税额(元) | 分类 |
|------|------|----------|----------|----------|------|
| 1 | 2024-01-15 | 增值税专用发票 | 1580.00 | 47.40 | 差旅费-住宿费 |
| 2 | 2024-01-16 | 普通发票 | 580.00 | - | 交通费 |
| 3 | 2024-01-16 | 普通发票 | 1200.00 | - | 业务招待费 |

## 合规性检查
✅ 发票抬头正确
✅ 税额计算准确
⚠️ 业务招待费注意限额（不超过当年营业收入的5‰）

## 报销汇总
| 费用类型 | 金额(元) |
|----------|----------|
| 差旅费 | 1580.00 |
| 交通费 | 580.00 |
| 业务招待费 | 1200.00 |
| **合计** | **3360.00** |
```

## 模块二：财务报表分析

**功能说明**：
- 自动识别报表类型（资产负债表、利润表、现金流量表）
- 三大报表联动分析，挖掘数据关联
- 杜邦分析法：ROE拆解为净利润率、总资产周转率、权益乘数
- 多维度分析：盈利能力、偿债能力、营运能力、现金流分析
- 生成"老板版"（简洁直观）和"专业版"（详细数据）报告
- 智能风险提示：识别财务异常、潜在风险

**触发词**：`/报表`

**使用示例**：
```
/报表 分析以下数据（杜邦分析）：
- 净利润：500万
- 营业收入：5000万
- 总资产：4000万
- 所有者权益：2500万
```

**输出格式（专业版）**：
```
## 杜邦分析报告

### 核心指标
| 指标 | 数值 | 行业参考 | 评价 |
|------|------|----------|------|
| ROE | 20% | 15% | 优秀 |
| 净利润率 | 10% | 8% | 良好 |
| 总资产周转率 | 1.25次 | 1.2次 | 良好 |
| 权益乘数 | 1.6 | 1.8 | 稳健 |

### ROE分解
ROE = 净利润率(10%) × 总资产周转率(1.25) × 权益乘数(1.6) = 20%

### 分析结论
1. 公司盈利能力较强，净利润率高于行业平均
2. 资产运营效率良好
3. 财务杠杆适中，风控稳健

### 老板版摘要
📊 公司ROE达20%，盈利能力优秀！
💰 投入1元资产可创造0.125元净利润
⚖️ 财务结构稳健，风险可控
```

## 模块三：税务计算器

**功能说明**：
- **个税计算**：支持最新7级超额累进税率，涵盖专项附加扣除（子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人）
- **社保公积金**：覆盖全国主要城市标准，支持自定义缴费基数
- **年终奖计税**：支持单独计税和合并计税两种方式对比
- **离职补偿金**：计算经济补偿金、赔偿金

**触发词**：`/个税`、`/社保`

**使用示例**：
```
/个税 计算：
月薪15000元，专项附加扣除：子女教育2000元+住房贷款1000元+赡养老人2000元
年终奖24000元，分别计算单独计税和合并计税
```

**输出格式**：
```
## 个税计算结果

### 月度个税计算
| 项目 | 金额 |
|------|------|
| 月薪 | 15,000.00 |
| 社保公积金(10.5%) | 1,575.00 |
| 专项附加扣除 | 5,000.00 |
| 应纳税所得额 | 8,425.00 |
| 月度个税 | 532.50 |

### 年终奖计税对比
| 计税方式 | 应纳税额 | 税后收入 |
|----------|----------|----------|
| 单独计税 | 720.00 | 23,280.00 |
| 合并计税 | 1,590.00 | 22,410.00 |
| **差额** | **870.00** | **870.00** |

### 建议
✅ 建议选择单独计税，可节省870元

### 年终奖计税过程（单独计税）
- 适用税率：3%（24000÷12=2000元）
- 应纳税额：24000 × 3% = 720元
```

## 工作流程

### 发票处理流程
1. **接收用户输入/图片** → 识别发票类型
2. **提取关键字段** → 校验数据完整性
3. **合规性检查** → 抬头、税号、重复报销
4. **分类汇总** → 按费用类型分组
5. **生成报告** → 输出表格和汇总数据

### 报表分析流程
1. **数据接收** → 识别报表类型
2. **指标计算** → 盈利能力、偿债、营运、现金流
3. **杜邦分解** → ROE拆解
4. **风险识别** → 异常数据预警
5. **报告生成** → 双版本输出

### 税务计算流程
1. **输入解析** → 识别计算类型和参数
2. **政策匹配** → 适用最新税率和扣除标准
3. **计算执行** → 分步计算
4. **结果输出** → 含计算过程和节税建议

### 团队审批流程
1. **提交申请** → 用户发起报销/付款/预算申请
2. **材料审核** → 检查附件和信息的完整性
3. **权限审批** → 根据角色分配审批人
4. **执行操作** → 通过后执行付款/记账等操作
5. **归档记录** → 记录完整审批链条

### 预算预警流程
1. **预算设定** → 设置各类别预算和预警规则
2. **执行追踪** → 实时监控实际支出
3. **预警判断** → 根据执行进度触发不同预警
4. **预警通知** → 推送预警消息给相关人员
5. **调整处理** → 支持预算调整申请

## 注意事项

1. **数据安全**：不存储用户财务数据，所有计算均在会话内完成
2. **政策时效**：税务计算基于最新政策，法规变化时自动更新
3. **结果参考**：计算结果仅供参考，实际申报以税务机关为准
4. **隐私保护**：发票照片等信息仅用于本次识别，不做他用
5. **团队数据隔离**：个人模式和团队模式数据完全隔离，切换模式不影响原数据
6. **权限最小化**：团队模式下，用户只能查看自己有权限的数据
