# Chinese Patent Disclosure Template Structure (技术交底书)

## Standard 7-Section Template

```
技术交底书
请认真阅读表格各项的要求，按规定如实、详尽地填写相关内容，可自行增加附页。

[Table with 2 columns: left=section title, right=content]

Section 1: 发明创造名称
  Guide: 应简单明确地表明发明的实质内容，可按其技术特点命名，也可按其用途命名，或技术、用途双重命名。避免使用宣传性、广告性词汇

Section 2: 所属技术领域
  Guide: 本发明创造直接所属或直接应用的具体技术领域

Section 3: 背景技术及现有技术的缺陷和不足
  Guide:
    ○1 简述在第二栏内容中填写的"所属技术领域"的发展历程
    ○2 说明现有技术的情况，并着重说明本发明创造是针对现有技术中的那些缺陷或不足进行改进的，尽量把"缺陷或不足"说得充分些
    ○3 对理解本发明内容无关的背景技术无需提供

Section 4: 发明构思描述
  Guide:
    ○1 简述各个结构分别实现什么功能。
    ○2 机械结构，电路（构造），化工医药产品要写清楚工艺流程，配方比例，配方方法，等等，这些专利主题，各有其特定的表述方式。需遵循专利保护的主题而详细描述。

Section 5: 本发明创造的优点或有益效果
  Guide:
    ○1 可针对第三栏"现有技术的缺陷和不足"来写

Section 6: 技术关键点和欲保护点
  Guide: 请简单扼要点明关键技术点即可；

Section 7: 具体实施例及附图
  Guide:
    ○1 实施例是实施发明内容的具体例子，可有多个实施例；注意请清楚、完整地描述实施例的技术方案，使本领域的普通技术人员人能够不需要创造性的劳动就可以理解/实现本发明；
    ○2 如有附图的，请提供CAD文件；
    ○3 对实施例的描述应当详细，有附图的，应当对照附图。
```

## Content Writing Style Conventions

### 发明创造名称
- Main name: `[Core Technique]方法、装置、设备及介质`
- Provide 4-5 optional names with different emphasis
- Recommend one, explain why
- Avoid abstract terms like "逻辑韵律" unless clearly defined

### 所属技术领域
- Pattern: `本发明属于[A]与[B]技术领域，具体涉及[具体技术]，尤其是一种[发明核心]的方法、装置、设备及介质。`

### 背景技术 (Section 3)
Write two sub-sections:
1. **发展历程**: Trace the evolution of the field, from early methods to current approaches
2. **现有技术的缺陷和不足**: Numbered items (○1, ○2, ...), each clearly stating ONE deficiency
   - Core claim: "现有技术的核心不足在于：[one-sentence summary of the core mismatch]"

### 发明构思描述 (Section 4)
- Start with: "本发明提出一种[invention name]。"
- Describe the overall flow/stages/phases in numbered format: (1), (2), (3)...
- If method: describe each phase's function and inputs/outputs
- If device: list modules and their connections
- End with: "装置包括：[modules list]"

### 优点 (Section 5)
- Numbered format: "第一，...第二，...第三，..."
- Each starts with "本发明" or "系统"
- Each addresses a specific deficiency from Section 3
- 5-6 items typically

### 技术关键点和欲保护点 (Section 6)
- Two sub-sections:
  1. **技术关键点**: Numbered (1), (2), (3)... brief technical highlights
  2. **欲保护点**: numbered (1), (2), (3)... enumerate core steps/structures
  - Include device/apparatus/medium claims

### 具体实施例 (Section 7)
- Multiple **实施例** (embodiments), each with a concrete scenario
- Each starts with a user query/input
- Describe step-by-step how the system processes it
- Include execution flow, failure handling, outcomes
- End with **附图说明**: numbered figures with "图N为..." descriptions

## Key Principles
1. Preserve ALL guide/instruction text from the template — it's part of the form
2. Guide text: 楷体 9pt; Content: 宋体 10.5pt
3. Output format: .docx (WPS-compatible) + optionally copy blank .doc template
4. Section titles: bold 宋体 10.5pt
5. Never remove or replace guide text — append content after it
