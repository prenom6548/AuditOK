## 角色定位

Kylin-CUA 是上层智能体调用真实桌面环境的通用入口。它不是某个特定应用的专用技能，而是用于把用户的自然语言目标交给可见 GUI 操作代理执行。

当用户的目标是“让电脑上的某个应用、网页或系统界面实际完成一件事”时，默认选择本 skill。不要等待用户显式说“使用 kylin-cua”或“调用 skill”。

## 触发规则

选择本 skill 的信号包括但不限于：

- 用户要求打开、启动、进入、切换、关闭、登录、搜索、下载、上传、安装、填写、提交、发送、预订、预约、加入、复制、粘贴、选择、保存、导出、导入、截图、处理弹窗或继续当前流程。
- 任务对象是桌面应用、浏览器、网页/Web 应用、系统设置、文件管理器、文件选择器、对话框、通知、编辑器、办公软件、聊天工具、会议软件、邮箱、网盘、播放器或任何当前可见窗口。
- 任务结果依赖当前屏幕内容、窗口布局、页面状态、账号登录状态、表单字段、下载提示、权限弹窗、文件路径或用户已经打开的上下文。
- 用户说“帮我操作”“帮我处理这个”“按页面提示来”“看看现在怎么弄”“把这个弄好”等含糊请求，但意图明显是继续操作电脑界面。

不要选择本 skill 的情况：

- 用户只是在问答、解释、翻译、写作、总结、设计方案、审查代码或修改仓库文件。
- 用户明确指定使用终端/CLI、代码、HTTP/API、Playwright、MCP 工具或某个应用专用连接器完成。
- 任务可以完全在当前对话中回答，不需要读取屏幕或操作任何外部界面。


## 执行约定

- 将用户的原始任务请求作为唯一的位置参数直接传给 Kylin-CUA。
- 原样保留用户请求中的姓名、账号标识、消息内容、文件路径、URL、日期、时间、表单内容和中文标点。
- 启动 Kylin-CUA 前，不要把用户请求改写成计划、总结或分步指令。
- 除非用户明确指定，否则不要用终端命令、Playwright、浏览器自动化、HTTP 调用、MCP 工具或无关的应用专用工具替代可见界面操作。
- 在前台运行进程，并等待它完成、中断，或进入需要用户接手的状态。
- 使用 600 秒超时。
- 启动后和进程结束后都要检查标准输出中的 `KYLIN_RESULT_JSON=...` 路径，并读取该 JSON 结果文件，不要只根据终端日志判断任务是否完成；如果外层超时，也应读取已打印路径下的当前结果文件。
- 如果结果文件的 `next_action_for_main_agent` 是 `ask_user_then_resume`，或 `status` 是 `need_user_assistance`，这不是普通失败，而是可恢复暂停：
  - 必须将顶层 `reason`、`user_action_required` 和 `resume_condition` 返回给用户。
  - 必须明确告诉用户：需要用户先手动完成 `user_action_required`，完成后回复“继续”或再次请求继续执行。
  - 在用户确认完成前，绝对不要根据 `reason` 自己生成新的 Kylin-CUA 指令，也不要再次调用 Kylin-CUA 重试同一任务。
  - 用户确认后，再次调用 Kylin-CUA 时，将原始任务、已完成摘要、上次阻塞原因、用户应已完成的操作和 `resume_condition` 一并写入任务请求；要求 Kylin-CUA 先检查恢复条件，满足后再继续执行。
- 如果结果文件的 `status` 是 `success`，再向用户报告任务完成；如果是 `max_steps`、`timeout`、`error` 或其他非成功状态，向用户说明原因，不要无条件重复调用。
- 如果任务涉及微信建群，必须原样保留用户的完整业务目标。微信建群时应提示下游模型：在微信主界面上方点击 `+` 号按钮进入创建入口，再选择“发起群聊”/“新建群聊”，不要先在聊天列表里搜索群聊。

## 启动


严格使用以下命令形态：

```bash
~/.local/share/kylin-cua/run/kylin-cua-launch "用户的任务请求"
```

如果系统 Python 环境缺少运行依赖，使用以下命令安装：

```bash
python3 -m pip install --break-system-packages \
  "pydantic>=2.0.0" \
  "python-dotenv>=1.0.0" \
  "openai>=1.0.0" \
  "langchain-core>=1.3.2,<2.0.0" \
  "langchain-openai>=0.1.0" \
  "pyautogui>=0.9.54" \
  "pyperclip>=1.9.0" \
  "pynput>=1.7.6" \
  "Pillow>=10.0.0" \
  "rapidfuzz>=3.0.0" \
  "PySide6>=6.6.0" \
  "oss2>=2.17.0" \
  "ddgs>=6.1.0"
```
