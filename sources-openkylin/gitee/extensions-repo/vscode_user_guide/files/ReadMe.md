## 目标
- 目标1：KylinIdeTeam开发、改造了一组VSCode插件，能满足基本的远程开发、C/C++开发、Qt开发、Python开发等。希望大家使用这些插件替换掉微软协议或闭源的组件；并反馈使用中的问题和意见，一起完善这些开发组件
- 目标2：AI工具能带来开发效率提升，希望大家能够将AI工具引入到开发工作中，多尝试AI工具，积累AI工具使用经验。提供AI工具帮助文档和使用示例来引导大家将AI工具应用到实际工作中，提高开发效率

## 简介
- 如果您习惯使用VSCode可以继续使用VSCode，不一定使用kylin-ide作为主程序
    * KylinIdeTeam开发、改造的VSCode插件，在VSCode和Kylin-IDE中都可以安装使用，不一定使用kylin-ide作为主程序
    * 插件已上传VSCode Marketplace（微软插件市场），直接使用VSCode也能够通过插件市场获取到KylinIdeTeam开发、改造的VSCode插件
- 本帮助文档使用场景
    * VSCode + 插件：本帮助文档主要面向使用 VSCode + 插件 的场景
    * Kylin-IDE + 插件：本帮助文档适用，可以类推。也可以通过Kylin-IDE的帮助菜单，跳转到Kylin-IDE的专用帮助文档
- 请使用KylinIdeTeam开发、改造的组件，替换微软协议或闭源组件，安装方法在具体解决方案章节有描述
    * KylinIdeTeam开发、改造的组件以解决方案的形式提供，解决方案以外的插件不做要求，可以在市场中下载使用
- 问题[反馈](./问题反馈.md)
    * 解决方案中的插件、组件问题，欢迎提反馈意见
    * 解决方案外的插件或编程语言支持，如有需求，也欢迎提反馈意见
    * 内网插件市场中缺少什么插件，欢迎提反馈意见
- 龙芯等特殊架构，通过远程开发支持；x86、飞腾也支持远程开发
    * 远程开发：利用SSH和Web技术，跨机器、跨操作系统、跨架构开发远端机器上的代码。由客户端和服务端组成
    * KylinIdeTeam[远程开发插件](./远程开发插件解决方案.md)：替代微软协议、未完全开源的Remote-SSH插件功能
    * KylinIdeTeam [WebIDE](./WebIDE解决方案.md)：利用SSH、浏览器、Web技术，实现类似Remote-SSH插件功能。能够利用浏览器做开发界面。客户端程序小巧

## 使用方法
- **【主程序】**：主程序可以使用VSCode或Kylin-IDE，不做限制   
- **【安装解决方案汇总插件】**：先安装“解决方案汇总插件”以便了解当前可获取的解决方案。在插件市场搜索KylinIdeTeam.kylin-dev-installer
- **【卸载微软插件】**：卸载微软对应插件，会在解决方案中提示，通常要替换的插件是微软协议或未完全开源，例如remote-ssh、cpp-tools等
- **【安装解决方案】**：在“解决方案汇总插件”引导下，根据开发场景安装解决方案
- **【重启VSCode或重载窗口】**：安装插件后，通常需要重启VSCode或通过`Ctrl + Shift + P`菜单`Reload Window`重载窗口，以便让新安装的插件生效
