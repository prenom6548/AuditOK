## APIChecker SIG

中国电子技术标准化研究院联合华为、麒麟、统信、中科方德、天翼云、长擎软件等多家操作系统厂商，依照操作系统领域国家标准、行业标准、团体标准等，研制标准配套测试验证工具，推动标准在操作系统社区版及商业发行版的应用。通过完善标准体系的建设和应用落地，从而推动操作系统的生态发展。
主要工作内容：研制API标准符合性检查工具，对操作系统提供的运行库（含库名、最低版本、共享对象名）、命令与工具、文件系统层次结构、权限与启动等的符合性进行检测。

## 工作目标

- 开发及维护操作系统标准符合性检查工具OSAPIChecker
- 开发及维护应用标准符合性检查工具APPAPIChecker
