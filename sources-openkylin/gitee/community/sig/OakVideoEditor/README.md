# OakVideoEditor SIG

## 工作目标

OakVideoEditor SIG 负责将 Oak Video Editor 引入 openKylin 生态，具体包括：

1. **代码贡献**：维护Oak Video Editor源代码，添加新功能和修复Bug；
2. **适配与移植**：完成 Oak Video Editor 在 openKylin 操作系统上的构建、适配与集成工作；
3. **软件包维护**：维护 openKylin 社区中 Oak Video Editor 相关软件包，跟进版本升级与依赖管理；
4. **功能优化**：针对 openKylin 平台特性进行性能调优与问题修复，提升国产平台视频编辑体验；
5. **生态拓展**：推动视频编辑工具链在 openKylin 上的落地，丰富开源操作系统创作类应用生态。
