# AIFramework兴趣小组（SIG）

AIFramework SIG致力于打造适配任何硬件环境的AI基础设施。包括AI优化、推理服务、AI框架、AI编译器等。为openKylin社区提供智能化算力底座。

## 工作目标

- 负责openKylin AI基础设施相关技术发展和决策
- 负责openKylin AI基础设施相关软件包的开发、维护、升级
- 负责对当前主流硬件环境及开源模型进行适配
- 负责openKylin AI基础设施相关问题解决
