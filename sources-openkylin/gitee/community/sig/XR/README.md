# XR SIG

扩展现实（XR）特别兴趣小组，专注于构建和完善 openKylin 的 XR 软件生态。致力于打造领先的 Linux XROS 发行版本。

## 工作目标

- 移植与维护 openHMD、OpenXR 驱动与运行时、OpenVR 兼容层等核心XR软件栈。
- 丰富XR应用与游戏库。
- 探索未来空间计算技术、XR 桌面环境、XRUI 及人机交互逻辑。
- 积极推动RISC-V架构下的XR软件栈移植。
