# HygonArch SIG

Hygon Arch SIG主要是围绕海光芯片，将海光C86芯片的架构特点、驱动功能、安全技术、上层软件生态等呈现出来。本SIG将围绕海光处理器的指令集优势，海光内嵌异构安全处理器的安全技术，以及海光C86上层软件应用技术的，结合openKylin社区已有的生态，扩大对芯片的应用。

## 工作目标

- 负责 openKylin HygonArch 版本的规划、制作、维护和升级

### 海光C86处理器优化指导

海光DevKit包括海光处理器加速库、系统库、存储库、内存库、压缩库调优指南
1）htcmalloc应用调优指南：https://c86.sourcefind.cn/documents/2/2002289458815373312
2）hjemalloc应用调优指南：https://c86.sourcefind.cn/documents/2/2002289458416914432
3）libhc应用调优指南：https://c86.sourcefind.cn/documents/2/2002289458031038464
所有优化库在openKylin2.0及以上版本验证通过，性能稳定。
