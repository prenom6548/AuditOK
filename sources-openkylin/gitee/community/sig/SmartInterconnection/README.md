# SmartInterconnection

## SIG组目标
Smart Interconnection SIG组致力于解决面向泛在计算的轻量化安全交互机制的技术问题，包括泛在计算环境中各种同质或异质的感知、统一设备交互机制高效存储并进行数据交互、构建面向泛在计算业务逻辑的智能人机交互机制等。

## 工作方向
- 设备交互：智能设备泛在交互的智能互联应用场景下异质异构资源的统一抽象和管理，以及应用运行时的资源调度等运行支撑的关键技术
- 数据交互：基于数据分等级处理和传输、数据降维压缩、数据保留和存储优化等原理，如何提升泛在计算场景的数据处理的效率，解决数据规模与存储、带宽、算力之间的矛盾
