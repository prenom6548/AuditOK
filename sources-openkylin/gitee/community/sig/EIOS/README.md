
## 具身智能操作系统

EIOS SIG(具身智能操作系统SIG组)致力于面向具身智能场景构建安全、高效且统一规范的基础软件支撑环境，打造基于openKylin的具身智能操作系统。

## 工作内容

1、构建基于openKylin的具身智能基础软件栈，探索openKylin+ROS+XX等完整运行支撑和仿真环境；

2、推动面向开放环境的具身智能安全韧性增强、即时任务调度、智能体运行支撑、内生演化框架等关键技术研究和系统实现；

3、构建面向多种平台或场景的统一操控支撑环境套件；

4. 推进面向具身场景的应用验证和生态建设，并把具身基础支撑的共性能力下沉，形成完善的具身智能操作系统底座。
