# PQCTransition (SIG)

PQCTransition SIG 是基于 OpenKylin 开源社区成立的后量子密码技术特别兴趣小组。
致力于推动后量子密码（PQC）算法的工程化和创新应用，以应对量子计算带来的安全挑战。工作组汇聚了密码专业学者、开发者和行业用户，专注于研究和开发抗量子攻击的密码技术，通过开源协作加速 PQC 算法的标准化和实际部署。工作组不仅关注算法的性能优化和安全性验证，还积极探索 PQC 在操作系统、通信协议和数据加密等领域的创新应用，助力 OpenKylin 社区构建量子安全的未来。欢迎对后量子密码技术感兴趣的伙伴加入我们，共同探索密码学的前沿领域，为信息安全保驾护航。

## 工作目标

PQCTransition SIG 致力于推动后量子密码（PQC）算法的迁移与应用。
工作组目标是技术探索并推动实施 PQC 算法迁移计划，逐步将传统密码学算法替换为抗量子攻击的 PQC 算法。通过与社区开发者合作，优化 PQC 算法的性能，确保其在实际场景中的高效运行。

工作组将在 OpenKylin 系统中开展 PQC 算法的集成测试，验证其兼容性和安全性，帮助社区成员和企业用户顺利过渡到量子安全的新时代。通过持续创新和协作，PQCTransition SIG 旨在为 OpenKylin 社区打造一个量子安全的未来。
