## 工作方向

- UI控制函数：在unity中使用预制体构建可以根据函数动态生成的ui，用ui选择并链接函数。
- 代码改写：C#的CodeAnalysis改写代码成制定格式，改写代码的中的方法适配ui。
- AI动态编译迭代：将AI生成的代码经过改写直接动态编译加载进主程序集，直接运行代码。
- 本地Web信息传输： 将主程序集设置一个服务器，动态的编译的程序集设置客户端，使用http来传递信息。
