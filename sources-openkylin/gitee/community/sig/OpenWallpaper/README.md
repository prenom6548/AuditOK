# OpenWallpaper SIG

## 简介

OpenWallpaper SIG（开放壁纸特别兴趣小组），专注于 openKylin 系统第三方壁纸生态的维护与开发，不止于静态图片，积极探索动态壁纸、交互式壁纸、AI生成壁纸等前沿形态，保持openKylin在桌面个性化领域的技术前瞻性。
