# HygonDCU SIG

HygonDCU SIG主要是围绕海光DCU（deep compute unit）加速卡，将海光AI计算的生态进行呈现，基于海光DCU加速卡的驱动、优化模型、优化算子、DTK平台等与openKylin的AI功能相结合，实现AI PC从操作系统到海光DCU的深度结合，完善和加速上层应用的生态和计算效率。

## 工作目标

- 负责 openKylin HygonDCU驱动、DTK版本更新，与openKylin AI功能将结合，进行优化

### 海光DCU产品介绍

K100-AI：国产化高性能GPGPU加速卡,采用通用架构设计，支持FP32、TF32、BF16、FP16.INT8等主流AI精度。提供成熟完善的异构软件栈兼容主流GPGPU开源生态。支持主流计算工具，包括主流AI框架和三方套件。
BW1000：采用 GPGPU 通用架构，支持全精度 AI 算力与Switch形式卡间高速互联，并通过 OpenDAS 社区提供开放开源的AI 扩展套件；兼容主流 GPGPU 生态，源码平滑迁移，可广泛赋能千行百业及 AI4Science、科学计算等多领域应用。
