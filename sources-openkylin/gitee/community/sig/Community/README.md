
## Community 兴趣小组（SIG）

Community SIG 是 openKylin 社区生态运营 SIG，负责社区治理体系建设、开发者生态运营、社区基础设施维护、品牌传播以及社区活动组织，推动社区用户向贡献者转化，提升社区影响力和活跃度。

## 工作目标

- 建设和维护社区运营体系，推动社区治理规范化；
- 策划组织社区活动、高校开发者培养及生态推广活动；
- 负责官网、论坛、文档等社区基础设施运营；
- 负责官方媒体渠道运营及社区品牌建设；
- 支撑社区常务委员会、技术委员会、生态委员会等社区治理活动；
- 建设社区数据分析体系，提升社区运营效率。
