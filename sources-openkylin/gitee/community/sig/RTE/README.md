# 实时性嵌入式 SIG（RTE SIG）

实时嵌入式小组（RTE=real time embeded）致力于实时性嵌入式方面的研究，通过内核实时性扩展、内核轻量化等技术，提升openKylin开源操作系统项目在实时嵌入式领域的实用性。

## 工作目标

1. 提高openKylin操作系统在实时性方面的可维护性和可扩展性，以满足不断变化的实时性需求和挑战。
2. 通过实时性增强提升用户对openKylin的信心，同时促进社区内的知识共享。
