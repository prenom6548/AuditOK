
## LLMsys(SIG)
LLMsys：大语言模型系统小组（LLMsys）致力于以大语言模型推理系统优化和加速为核心，深度融合大语言模型（LLM）与操作系统技术，特别强调推理阶段的性能提升、资源效率优化，以及依托 openKylin 操作系统特性释放推理系统的实用价值。通过将推理优化技术与麒麟系统深度结合，一方面打造适配麒麟系统的低延迟、高吞吐量推理运行环境，实现推理系统与操作系统资源调度的协同优化；另一方面借助推理加速能力，让大语言模型在系统端的智能应用（如自然语言交互、智能服务）响应更快、占用资源更少，进一步优化操作系统的智能服务体验。

## 工作目标
LLMsys 的目标是围绕大语言模型推理系统优化和加速，结合操作系统技术，解决以下关键问题：​

1.推理系统性能优化：基于操作系统的资源管理特性，解决大语言模型推理阶段的延迟降低、吞吐量提升、算力利用率优化等问题，例如通过算子优化、内存调度协同、硬件加速适配等手段，确保推理过程高效稳定。​

2.推理 - 系统资源协同：利用操作系统的资源调度能力，解决推理系统与系统其他服务的资源竞争问题，实现推理任务的动态资源分配，在保证推理性能的同时，不影响操作系统核心功能的正常运行。​
