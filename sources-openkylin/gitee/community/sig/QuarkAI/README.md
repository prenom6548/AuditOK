# QuarkAI Special Interest Group (SIG)

## 工作目标

QuarkAI SIG自2023年7月5日伴随开放麒麟（openKylin）1.0版本的发布而启动，作为社区的核心组成部分，肩负起构建并强化整个麒麟AI生态系统的重任。该小组专注于整合与开发先进的AI平台技术，在创新技术应用和生态系统建设方面不断努力，旨在使开放麒麟操作系统在人工智能领域展现出业界领先的能力。

随着AI技术的不断发展，QuarkAI SIG坚定信念，致力于营造一个强大且活跃的AI生态环境，以提供给用户更为智能、便捷、高效的AI服务体验，并积极推动国产开源操作系统在AI领域的长远发展与壮大。这一追求不仅是对技术创新的执着，更是QuarkAI SIG对国家信息技术自主可控战略的响应，以及在全球开源事业中贡献力量的实际行动。
