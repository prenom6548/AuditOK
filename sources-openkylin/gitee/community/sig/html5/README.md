## HTML5兴趣小组（SIG）

HTML5 SIG专注于打造基于Web（HTML5、CSS、Javascript、WASM等）技术的终端操作系统桌面环境，负责相关代码软件仓库的规划、版本维护和升级工作。

## 工作目标

- 负责基于HTML5技术打造轻量级移动终端操作系统桌面环境
- 负责构建Web移动应用运行基础环境
- 负责相关以Web技术为基础的移动应用的维护
