## OpenDDE SIG

OpenDDE SIG致力于维护openKylin的DDE桌面环境相关组件，专注于打造美观易用、极简操作的桌面环境。主要负责桌面、启动器、任务栏、控制中心、窗口管理器等组件维护。


## 工作目标

负责维护openKylin系统的DTK组件库、DDE桌面环境以及特色应用软件。
