## 终端计算智能服务（SIG）
  SIG（EdgeAI SIG组负责面向边缘设备的轻量化 AI 服务栈，解决低算力设备实时推理与隐私保护在openKylin PC、信创、服务器、边缘计算等生态设备上的适配开发、版本维护、源码仓库管理和开发手册编写等工作，致力于打造适配openKylin系统终端计算智能服务。

## 工作目标
-轻量模型优化：
  开发模型压缩与量化工具链，支持 ARM NPU/边缘 GPU 适配，实现模型 50% 体积压缩；
  构建边缘模型仓库，提供预训练模型（如视觉检测、语音唤醒）的即插即用部署。
-边缘-云协同框架：
  设计动态任务调度机制，支持敏感数据本地处理、非敏感任务云端卸载；
  开发低延迟通信协议，优化边缘节点间数据同步效率。
-安全隐私保障：
  集成联邦学习框架，实现跨设备协作训练；
  为边缘应用提供差分隐私 SDK
