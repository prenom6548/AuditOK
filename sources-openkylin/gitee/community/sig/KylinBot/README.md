# KylinBot兴趣小组（SIG）

KylinBot SIG小组致力于系统级AI智能体的规划、设计与开发工作。本SIG聚焦于将人工智能技术与操作系统深度融合，构建具备自主感知、决策与执行能力的智能体系统，为用户提供更智能、更便捷的桌面交互体验。

KylinBot作为openKylin操作系统的AI智能体项目，旨在打造一个能够理解用户意图、自主调用系统能力、高效完成复杂任务的智能助手。通过接入KART AI子系统，实现自然语言交互、智能任务编排、自动化流程执行等核心能力，推动操作系统从工具型向智能型演进。

## 工作目标

- **KART AI子系统接入**：完成与KART AI子系统的深度集成，实现AI能力在操作系统层面的落地应用
- **智能体框架构建**：设计并实现可扩展的智能体架构，支持多模态交互、任务规划与自动化执行
- **自然语言交互**：构建流畅的自然语言理解与生成能力，让用户能够通过对话方式操控系统
- **系统能力封装**：将操作系统核心能力（文件管理、系统设置、应用调度等）封装为智能体可调用的工具集
- **场景化智能服务**：针对办公、开发、日常使用等典型场景，提供智能化的解决方案和服务
