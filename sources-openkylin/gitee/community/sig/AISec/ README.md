
## AISec (SIG)
AISec：智能安全小组（AISec ）致力于将人工智能与系统安全深度融合，特别强调端大模型自己的安全性和利用大模型来解决系统方面的安全问题。通过将大模型为代表的AI技术融入openKylin操作系统，一方面提供安全可靠的大模型，实现麒麟系统大模型安全防御能力，另一方面利用大模型技术解决传统系统面临的安全问题。

## 工作目标
AISec的目标是通过深度融合AI和系统安全，解决以下关键问题：

1. 大模型安全：基于大模型，解决大模型的内容安全问题。
2. 系统安全： 利用大模型技术解决传统的系统安全问题。
