# 星载操作系统研发小组
## 职责和目标
Space SIG 将聚焦关键应用场景，致力于打造一个全面的空间智能操作系统软件栈：  
第一，定义空间级操作系统的基线，将针对星载异构硬件平台，提供统一的内核抽象和南向适配层，重点解决混合关键性部署和深度功耗管理等问题；  
第二，构筑空间系统的高可靠堡垒，将单粒子翻转防护、故障自愈等空间刚性需求，内化为操作系统的原生特性，通过全栈加固保障系统安全；  
第三，面向高动态星座环境，重点突破星间算力实时感知、分布式动态任务调度及“云-星”跨域协同管控等关键技术，构建“云端全局协调+星间分布自治”的混合调度架构，实现星上资源在拓扑变化、链路不稳定条件下的自组织与高效利用；  
第四，研究智能应用在卫星资源受限环境下的可靠运行方法，构建覆盖算力效能的全栈可观测性体系，构建覆盖应用任务、系统资源、异构算力、功耗温度及节点健康状态的可观测体系，实时评估算力负载均衡度与资源利用效率。
