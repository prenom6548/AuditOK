## OpenB2G兴趣小组（SIG）

OpenB2G专注于基于Linux+HTML5技术体系的终端操作系统解决方案，负责相关代码软件仓库的规划、版本维护和升级工作。

## 工作目标

- 负责基于Linux+HTML5技术体系构建终端操作系统解决方案
- 负责构建终端操作系统HTML5应用程序
- 负责构建终端操作系统核心服务框架及应用运行支撑环境
- 负责构建终端操作系统多终端平台适配框架
