# RFL SIG

openKylin RFL SIG致力于推动Rust for Linux在openKylin社区的发展，聚焦Linux内核中Rust基础设施的开发、维护与推广，促进Rust语言在openKylin内核及相关组件中的应用。

## 工作目标

- 推动Rust for Linux相关技术在openKylin社区的落地与发展
- 维护Linux内核Rust基础设施及相关组件
- 促进Rust语言在内核开发领域的生态建设
- 推动Rust驱动及内核模块的开发与创新
