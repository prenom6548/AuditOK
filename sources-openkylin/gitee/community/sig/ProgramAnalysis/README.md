# ProgramAnalysis 小组 (SIG)

## 简介

ProgramAnalysis 小组（SIG）由北京航空航天大学网络空间安全学院负责项目和代码的维护，致力于将学院在软件安全和程序分析领域的教学与研究成果应用于openKylin系统。小组依托学院师生在系统软件安全等方面的技术积累，通过先进的程序分析技术保障openKylin社区软件的安全可靠。小组旨在通过教学培养专业人才，为国产操作系统生态的高质量发展贡献力量。

## 工作目标

- 聚焦软件安全与程序分析技术，研究静态分析与动态分析在系统软件中的应用，尤其是缺陷检测和漏洞挖掘。
- 将研究成果应用于openKylin社区软件开发与测试，保障国产系统软件的安全可靠。
- 结合“操作系统”、“软件分析与安全”等北航网安课程，在openKylin社区上提供教学和实验材料，培养系统软件安全人才。
- 组织北航网安学院师生进行openKylin社区的开源贡献。
