## ConfidentialComputing SIG

ConfidentialComputing SIG 利用 ARM 架构上的可信执行环境TEE 为设备上的基础设施以及神经网络提供安全增强，实现机密计算目标

## 工作目标

1. 开发维护 TEE 与 REE 两个世界各自的推理框架以及对应算子库
2. 维护 REE 侧算子与主流深度学习框架的集成（如 PyTorch 的 TorchScript）并提供相应的高级语言调用接口
3. 实现基于新一代可信执行环境ARM CCA的机密容器
