# FlagOS SIG

FlagOS SIG 致力于负责 FlagOS 开源软件包在 openKylin 上的移植，发布和维护。发布基于 openKylin 的 FlagOS 版本，并进行 FlagOS 软件包打包、BUG 修复等工作。

FlagOS（众智 FlagOS）是由北京智源研究院牵头、多家国内外机构共建的开源统一 AI 系统软件栈，定位为 “大模型时代的跨芯片操作系统”，解决 AI 硬件生态碎片化、模型跨芯片迁移成本高的痛点。

## 工作目标

  1. 负责 FlagOS 对 openKylin 的适配和移植。
  2. 负责后续 FlagOS 在 openKylin 的软件包更新和维护。
  3. 基于 openKylin 和 FlagOS 组合开源的 FlagOS 演示方案。
