# AISubsystem兴趣小组（SIG）

AISubsystem SIG小组致力于OpenKylin AI子系统的规划、维护和升级工作

## 工作目标

- 负责AI子系统相关软件包的规划、维护和升级
- 管理本地和云端大模型，屏蔽各个大模型和框架的差异，提供AI基础能力和特定场景相关的SDK接口
- 打造麒麟 OS Agent
