# BoLe
伯乐-人力资源场景大模型
## 工作目标
BoLe SIG组是由珠海必优科技面向“人力资源”场景下的垂类AI大模型的构建、训练与部署，形成的伯乐AI应用用于简历写作、简历润色、人岗匹配、JD写作等一系列场景，以实现人力资源场景下生产力的升级。

## 工作内容
- 1、负责伯乐AI应用在社区的开源与维护升级；
- 2、负责伯乐插件跟AI助手或桌面第三方应用的打通；
- 3、链接社区广大爱好者，促进AI应用生态发展。
