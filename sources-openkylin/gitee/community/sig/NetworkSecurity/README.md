## NetworkSecurity SIG

NetworkSecurity SIG研发组，致力于基于开源麒麟系统打造一套全面的网络安全综合套件，以满足当前及未来网络安全领域的需求。


## 工作目标
常用网络安全工具的兼容性移植：针对市场上广泛使用的网络安全工具，进行深入的兼容性研究，确保这些工具能够在开源麒麟系统上无缝运行。

基于开源麒麟的网络安全工具开发：依托开源麒麟系统的强大功能和生态优势，开发适用于六大安全方向工具集合，包括移动安全，云安全，web安全，数据库安全，漏洞扫描，辅助流量分析，应急响应等场景的工具和分析脚本。
