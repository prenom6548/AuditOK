## Compliance SIG组简介
开源合规与知识产权保护SIG将作为社区这一重要关注方向的主体，以操作系统开源合规治理为抓手，积极对接“可信开源合规计划”，完善openKylin “可控开源”体系，积极探索知识产权保护与开源合规理论创新、推广普及和实践落地。

## SIG组目标
1）定期组织开展开源合规领域各重点方向专题研讨，邀请社区内外合规领域专家分享交流，探讨openkylin社区合规治理需求与方案。  
2）与社区其他sig合作，建立起openkylin社区基本合规规范要求和制度，协助基础设施团队实现合规规范检测工程化落地。  
3）建立起完善的研讨交流平台，在某一领域（如桌面图形应用）形成合规实践影响力，吸引对开源合规感兴趣的各类人士主动参与。  
4）提供简单易懂的开源合规知识产权保护学习材料，组织各类社区活动，面向普通开发者与爱好者普及开源合规理念与基本知识。  
5）促使社区人人关注开源合规与知识产权保护，识别潜在合规隐患，形成良性互动氛围，简单问题自发更正，复杂问题及时反馈。  
6）管理平台，开源代码扫描工具等。  
7）快速检测出社区的代码中使用开源软件的痕迹（包括许可证信息和特殊专利条款信息）。
