# RTOS

openKylin RTOS小组致力于实时内核优化、中间件适配及工具链支持，研究轻量级实时内核、低延迟调度算法、高可靠性机制等关键技术。生态建设涵盖工业自动化、汽车电子、智能设备及物联网等行业，推动混合部署、边缘计算与实时系统融合，共建开放协作的实时生态体系。

## 工作目标

- 面向工业控制、汽车电子、智能终端等领域输出行业解决方案。
- 构建RTOS中间件适配体系，完善开发工具链与测试框架。
- 负责RTOS解决方案在主要硬件平台的适配和运行。
- 联合开发者与企业共建开源生态，推动实时系统与混合部署、边缘计算融合创新。
