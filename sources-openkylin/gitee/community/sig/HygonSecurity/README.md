# HygonSecurity SIG

HygonSecurity SIG主要基于海光C86处理器架构，致力于打造自主可控的全栈式技术体系，主要覆盖国密算法、可信计算、机密计算及硬件虚拟化等技术领域，提供从底层硬件适配到上层应用开发的完整软件栈与技术文档，提供客户与生态伙伴的全方位安全解决方案，如需生态合作或技术支持，请联系：securitytech@hygon.cn

## 工作目标

- 负责openKylin发行版海光安全特性的适配、功能应用、系统验证等工作。
