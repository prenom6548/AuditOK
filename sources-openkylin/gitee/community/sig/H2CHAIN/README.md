## SIG组名称
H2CHAIN

H2CHAIN（海河信创链）1.0版本由天津大学、先进计算与关键软件（信创）海河实验室、华夏好瑞、麒麟软件联合发布。海河信创链实现了多节点信创环境下万级吞吐量、构建了聚焦全方位评价体系的信创链性能测试平台、打造了支持大规模异构区块链互通互联的高性能信创跨链平台。

## 工作目标

H2CHAIN SIG致力于海河信创链的研发迭代，包括但不限于：
1）信创环境的多元深度适配；
2）信创区块链性能突破；
3）代码自主能力优化。
