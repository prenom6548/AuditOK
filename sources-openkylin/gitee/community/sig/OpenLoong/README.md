# OpenLoong SIG

OpenLoong SIG致力于推进openKylin与OpenLoong开源人形机器人项目的深度合作，优化和适配openKylin系统以支持OpenLoong的全栈开源人形机器人解决方案，并探索操作系统层面对人形机器人的创新优化。

## 工作目标

- 优化openKylin在机器人场景下的系统性能，特别是实时性、可靠性和设备驱动程序支持等关键指标
- 打包和维护机器人开发所需的板级支持包以及常用软件栈
- 与OpenLoong机器人开源社区合作，在系统层面展开联合调优的探索，提升整体性能。
