# InternationalPromotion SIG

负责openKylin操作系统的国际化推广，开展国际交流会议，提升国产操作系统国际影响力，致力于世界各地爱好者加入openKylin社区建设。

## 工作目标

- 加强openKylin操作系统国际化交流合作
- 负责开展社区国际化推广活动
- 收集并解决国际用户使用反馈
- 维护openKylin社区国际化建设
- 提高社区平台国际活跃用户数等

# International Promotion SIG (English)

Contributions from any region are welcome to the International Promotion SIG.

Contributions may include improvements to documentation, international outreach,
Collecting and resolving feedback from international users, and participation
in community discussions.

New contributors should start with updating the documentation, contributing to
Increase the number of international active users on the community platform, or
by participating in discussions of issues.
