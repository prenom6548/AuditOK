# AgentOS SIG

AgentOS SIG 致力于推动面向操作系统的 Agent 生态建设，围绕 AI PC 与智能操作系统场景，建设从模型推理、Agent 运行时、核心能力组件、评测基准到系统级 Agent 应用的基础设施与协作规范。SIG 维护范围覆盖统一模型推理服务、Agent Runtime、Agent Harness、记忆、规划、技能、工具、调度、优化、评测与基准测试等基础能力，并孵化 system-agent、os-agent、kylin-agent、computer-use-agent 等面向操作系统的人机协同与自动化应用。

AgentOS SIG 希望通过开放的组件体系和工程实践，降低操作系统接入大模型与智能代理能力的门槛，支持系统任务理解、桌面环境交互、统一推理接入、工具调用、多步骤规划、长期记忆、任务调度、执行评测、基准测试、性能优化与多智能体协作等能力在 openKylin 生态中持续演进。

## 工作目标

- 定义 AgentOS 相关的架构设计、接口规范、安全边界与最佳实践，形成可复用、可扩展的操作系统 Agent 技术体系。
- 维护与孵化操作系统 Agent 应用，包括 system-agent、os-agent、kylin-agent 与 computer-use-agent，探索系统任务助手、桌面自动化、Computer Use Agent、应用控制与人机协同交互能力。
- 建设统一模型推理服务，维护 uni-model-infer 与 unified-llm-inference，提供面向多模型、多后端、多部署形态的推理接入、服务封装与能力适配。
- 完善 Agent 运行时与执行框架，维护 agent-rt、agent-runtime 与 agent-harness，支持任务编排、执行隔离、工具调用、流程管理、运行观测与可验证执行。
- 建设 Agent 核心能力组件，维护 agent-memory、agent-planning、agent-skills、agent-tools、agent-schedule 与 agent-optimization，支撑记忆管理、任务规划、技能注册、工具生态、任务调度、执行优化与效果提升。
- 建设 Agent 评测与基准体系，维护 agent-evaluation 与 agent-benchmark，沉淀面向系统任务、桌面交互、工具调用、规划执行和多智能体协作的评测方法、数据集与基准用例。
- 推动多智能体协作与系统集成方案，沉淀跨组件协同、插件化扩展、权限控制、日志追踪、稳定性治理和端侧资源协同经验。
- 推动社区 AgentOS 生态建设，鼓励开发者参与 SIG 维护包共建、场景验证、文档完善与上下游项目协作。
