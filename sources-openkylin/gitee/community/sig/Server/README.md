## Server SIG小组

Server SIG负责负责openKylin服务器版本的研发、构建和适配工作.

## 工作目标

1. 版本规划与集成：根据社区版本发布周期，制定服务器相关功能的版本计划，协调代码开发、测试与集成，确保功能按时纳入社区发行版. 
2. 硬件兼容性支持：与硬件厂商合作，推动openKylin在不同服务器硬件上的适配与性能优化，提升系统兼容性与运行效率.
