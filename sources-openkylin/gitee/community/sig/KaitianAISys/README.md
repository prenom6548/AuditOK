## 网络与智能SIG

### 工作目标
“网络与智能”SIG组致力于构建安全高效的网络基础与智能化管理能力，推动AI与网络深度融合，打造可信、智能的操作系统生态。
具体内容：
1、打造智能化浏览器内核能力。聚焦国产浏览器的核心研发，推进智能化渲染、视频编解码、网页理解与推荐等关键技术，提升在国产系统上的整体性能与用户体验。
2、构建浏览器原生AI能力。深度融合大模型、MCP/Agent 框架与浏览器插件生态，探索智能搜索、智能问答、智能写作、网页内容摘要与自动化测试等AI场景落地，打造新一代“AI 浏览器”。
3、推动网络与智能协同生态。搭建面向国产系统和硬件的开放生态，联合社区伙伴，推动浏览器在智能网络、安全通信、多终端互联等方向的标准制定与应用创新，形成面向未来的智能网络基础能力。
