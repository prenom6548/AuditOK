
## DeveloperCurated 兴趣小组（SIG）

DeveloperCurated SIG组主要负责社区开发者提交的第三方软件包，包括相关比赛优秀作品的存放（如openKylin麒麟杯大赛、开放原子开源大赛、研究生大赛等），优秀个人爱好者提交的小工具、应用等。

## 工作目标

- 负责优秀作品与优秀人才的集中管理
- 负责开发者提交的第三方软件包的管理
