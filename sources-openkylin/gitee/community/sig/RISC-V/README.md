# RISC-V SIG

负责RISC-V开源软件包的维护。发布openKylin的RISC-V 版本，进行软件包构建、系统构建等工作。

## 工作目标

- 负责 openKylin RISC-V 版本的规划、制作、维护和升级
- 负责RISC-V同x86、ARM间的应用兼容技术探索
