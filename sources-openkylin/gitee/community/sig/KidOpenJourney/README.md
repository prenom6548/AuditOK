# 少儿开源操作系统体验之旅小组 (SIG)

KidOpenJourney：聚焦于 “少儿群体与国产开源操作系统的连接”（Kids' Open Source Journey）探索适合少儿认知水平的国产开源操作系统学习路径，降低入门门槛；以少儿用户视角反馈国产开源操作系统在易用性、教育工具适配等方面的优化建议；推动少儿编程学习与国产操作系统应用开发的结合，形成 “学习 - 实践 - 贡献” 的良性循环。

## 工作目标

聚焦于 “少儿群体与国产开源操作系统的连接，解决以下关键问题：

- 形成可持续的少儿开源贡献模式，让更多孩子理解 “开源协作” 的意义；

- 为国产开源操作系统的教育场景优化提供少儿用户的真实需求参考；

- 培养具备开源意识的少儿开发者，助力国产开源生态的长期发展；

- 树立少儿参与开源的示范标杆，总结 SIG 运营经验，形成《少儿参与开源社区指南》，向其他开源项目推广，推动行业关注低龄群体在开源生态中的独特价值。
