# ZephyrProject

openKylin ZephyrProject 小组致力于基于 Zephyr 的实时操作系统研究与社区共建，面向工控、具身智能等需要确定性响应与软硬协同的场景，推动 Zephyr 在国产硬件平台上的可用性与生态完善，并与 openKylin 及上游 Zephyr 社区形成良性互动。

## 工作目标

- 为工控、具身智能等领域提供基于 Zephyr 的实时系统能力与参考方案
- 推进 Zephyr 在主要国产及主流硬件平台上的移植、适配与长期维护
- 完善内核、驱动、中间件及开发工具链等基础能力，降低开发者使用门槛
- 探索实时 OS 与 Linux、虚拟化、机器人软件栈等的协同集成路径
- 跟踪 Zephyr 及嵌入式实时领域的前沿技术，积极向上游回馈补丁与经验
- 与 openKylin 其它 SIG 协同，共同推进开源实时操作系统生态建设
