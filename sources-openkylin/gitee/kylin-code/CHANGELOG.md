## v0.3.0
1. 新增安装引导功能

    该功能用于引导用户根据开发场景安装基础功能插件、安装依赖软件、配置基本开发环境。支持在线安装，需要连接互联网下载插件和依赖软件。
    > 新增功能仅支持Openkylin X86操作系统

2. 使用

    kylin-code首次启动时进入安装引导界面，非首次启动可以通过菜单中的帮助->打开安装器选项进入安装引导界面，根据页面提示选择开发场景，进行插件和依赖软件下载安装，配置基本开发环境。

## v0.1.0

此版本适用于Openkylin X86版本操作系统。
本次重大更新版本，更新内容较多，主要有以下更新内容：
1. 新增中文显示界面。
2. 修改linux中默认界面的titlebar风格为custom。
3. 插件侧边页面中插件过滤按钮下拉菜单中添加KylinCode分类过滤菜单.
4. 插件详情页面添加显示插件的downloadUrl。
5. 关闭插件的自动更新。
6. 解决安装deb时报错。
7. 新增toolbar工具栏,位于标题栏和菜单栏下面,具有隐藏显示功能,工具栏中为一些快捷按钮。
8. 开始页面中新增必读栏目，对插件分类和依赖管理进行说明。
9. 帮助菜单增加插件依赖管理器和离线插件管理器入口菜单。
10. 开始页面“无限扩展性”右侧是vscode插件,改为我们Team开发定制的插件, 修改svg中的png图片和搜索命令。
11. 文件菜单下,添加选择显示语言的子菜单。
12. 添加卸载删除插件和软件用户数据: deb包,只有当执行dpkg --purge或者-P时,会删除当前用户默认的软件用户数据。
13. 修改组织名称为KylinIdeTeam。
14. 启动时argv.json中添加ignore-certificate-errors参数,为true时忽略https请求时的证书。
15. 修改集成自编译的插件js-debug为内置插件。
16. js调试插件，没有进行中文显示,添加插件新ID“KylinIDETeam.js-debug”对应的中文显示文件。
17. 添加IDEVersion字段显示版本号，设置版本号为0.1.0,在about页面和系统命令行显示kylin-code版本。
18. 更改软件名称为Kylin-Code。
19. 修复项目创建后,帮助菜单缺少插件依赖管理器和离线插件管理器菜单项。
20. 修改欢迎页面和walkthrough中软件名称为Kylin-Code。
21. 侧边栏和工作区信任移除外部链接。
