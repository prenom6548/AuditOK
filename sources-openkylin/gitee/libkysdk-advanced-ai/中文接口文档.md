## 1. 概述

本SDK（libkysdk-knowledge-base）是一个功能完整的知识库管理和智能对话C语言SDK，专为企业级应用设计。它提供了从文档处理到智能问答的全套解决方案，支持多种文档格式，具备高性能的向量检索和自然语言处理能力。

### 1.1 SDK架构

```
┌─────────────────────────────────────────────────────────────┐
│                    应用层 (Application Layer)                │
├─────────────────────────────────────────────────────────────┤
│                    SDK接口层 (SDK Interface)                 │
├─────────────────────────────────────────────────────────────┤
│  会话管理  │  知识库管理  │  文档处理  │  聊天功能  │  配置管理  │
│ Session   │ Knowledge   │ Document  │   Chat    │  Config   │
│ Manager   │    Base     │ Process   │ Function  │ Manager   │
├─────────────────────────────────────────────────────────────┤
│                    核心服务层 (Core Services)                │
│  向量检索  │  文档解析  │  AI模型  │  索引管理  │  缓存系统   │
├─────────────────────────────────────────────────────────────┤
│                    数据存储层 (Data Storage)                 │
│  文件系统  │  向量数据库  │  元数据库  │  缓存存储             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 基础类型和错误码

### 2.1 错误码定义

SDK使用分层错误码系统，便于快速定位和处理问题。错误码按功能模块分组，每个模块占用100个错误码空间。

```c
typedef enum {
    KB_SUCCESS = 0,                     // 操作成功

    /* 通用错误 (1-99) */
    KB_ERROR_INVALID_PARAM = 1,         // 无效参数
    KB_ERROR_PERMISSION_DENIED = 2,     // 权限被拒绝
    KB_ERROR_INTERNAL = 3,              // 内部错误
    KB_ERROR_TIMEOUT = 4,               // 操作超时
    KB_ERROR_INITIALIZATION = 5,        // 初始化失败

    /* 网络错误 (100-199) */
    KB_ERROR_NETWORK = 100,             // 网络错误
    KB_ERROR_NETWORK_TIMEOUT = 101,     // 网络超时
    KB_ERROR_NETWORK_CONNECTION = 102,  // 连接失败
    KB_ERROR_NETWORK_AUTHENTICATION = 103, // 认证失败

    /* 会话错误 (200-299) */
    KB_ERROR_SESSION_INVALID = 200,     // 无效会话
    KB_ERROR_APP_ID_INVALID = 201,      // 无效应用ID

    /* 知识库错误 (300-399) */
    KB_ERROR_KB_NOT_FOUND = 300,        // 知识库不存在
    KB_ERROR_KB_ACCESS_DENIED = 301,    // 知识库访问被拒绝
    KB_ERROR_KB_CORRUPTED = 302,        // 知识库已损坏

    /* 文档错误 (400-499) */
    KB_ERROR_DOC_NOT_FOUND = 400,       // 文档不存在
    KB_ERROR_DOC_TOO_LARGE = 401,       // 文档太大
    KB_ERROR_DOC_INVALID_FORMAT = 402,  // 文档格式不支持
    KB_ERROR_DOC_UPLOAD_FAILED = 403,   // 文档上传失败
    KB_ERROR_DOC_PROCESSING = 404,      // 文档处理中
    KB_ERROR_DOC_ACCESS_DENIED = 405,   // 文档访问被拒绝
    KB_ERROR_DOC_CORRUPTED = 406,       // 文档已损坏
    KB_ERROR_DOC_EMPTY = 407,           // 文档为空

    /* 检索错误 (500-599) */
    KB_ERROR_RETRIEVAL_FAILED = 500,    // 检索操作失败
    KB_ERROR_RETRIEVAL_NO_RESULTS = 501, // 没有找到结果
    KB_ERROR_RETRIEVAL_INVALID_QUERY = 502, // 无效查询
    KB_ERROR_RETRIEVAL_TIMEOUT = 503,   // 检索超时

    /* 聊天错误 (600-699) */
    KB_ERROR_CHAT_MODEL_UNAVAILABLE = 600, // 聊天模型不可用
    KB_ERROR_CHAT_CONTEXT_TOO_LONG = 601,  // 聊天上下文过长
    KB_ERROR_CHAT_ID_NOT_FOUND = 602,      // 聊天ID不存在
    KB_ERROR_CHAT_REQUEST_NOT_FOUND = 603, // 聊天请求ID不存在

    /* 配置错误 (700-799) */
    KB_ERROR_CONFIG_INVALID = 700,      // 无效配置
    KB_ERROR_CONFIG_MISSING = 701,      // 缺少配置

    KB_ERROR_UNKNOWN = 1000,            // 未知错误
} KBError;
```

#### 错误码分类说明

| 错误码范围 | 分类 | 说明 |
|-----------|------|------|
| 0 | 成功 | 操作成功完成 |
| 1-99 | 通用错误 | 参数错误、权限错误等通用问题 |
| 100-199 | 网络错误 | 网络连接、超时、认证相关错误 |
| 200-299 | 会话错误 | 会话管理相关错误 |
| 300-399 | 知识库错误 | 知识库操作相关错误 |
| 400-499 | 文档错误 | 文档处理相关错误 |
| 500-599 | 检索错误 | 搜索和检索相关错误 |
| 600-699 | 聊天错误 | 对话功能相关错误 |
| 700-799 | 配置错误 | 配置参数相关错误 |
| 1000+ | 未知错误 | 其他未分类错误 |

### 2.2 文档处理状态

文档处理是一个多阶段的异步过程，每个阶段都有对应的状态标识。

```c
typedef enum {
    KB_DOC_STATUS_PENDING = 0,          // 等待处理 - 文档已提交，等待处理队列
    KB_DOC_STATUS_PARSING = 1,          // 文档解析中 - 正在解析文档内容和结构
    KB_DOC_STATUS_INDEXING = 2,         // 索引建立中 - 正在建立向量索引
    KB_DOC_STATUS_COMPLETED = 3,        // 处理完成 - 文档已完全处理，可用于检索
    KB_DOC_STATUS_ERROR = 4,            // 处理出错 - 处理过程中发生错误
} KBDocumentStatus;
```

#### 文档处理流程

```
文档上传 → 等待处理 → 文档解析 → 向量化 → 索引建立 → 处理完成
   ↓         ↓         ↓        ↓       ↓        ↓
 UPLOAD   PENDING   PARSING  VECTORIZING INDEXING COMPLETED
                                ↓
                            如果出错 → ERROR
```

#### 状态转换规则

- `PENDING` → `PARSING`: 文档开始解析
- `PARSING` → `INDEXING`: 解析完成，开始建立索引
- `INDEXING` → `COMPLETED`: 索引建立完成
- 任何状态 → `ERROR`: 处理过程中出现错误

### 2.4 内存管理

SDK提供了专门的内存管理函数，用于释放SDK内部分配的内存。

#### 2.4.1 字符串内存释放

```c
void kb_free_string(char *str);
```

**功能**: 释放SDK返回的字符串内存
**参数**:
- `str`: 要释放的字符串指针（可以为NULL）
**返回**: 无
**线程安全**: 是

**使用场景**:
- 释放`kb_generate_request_id()`返回的字符串
- 释放`kb_knowledgebase_create()`返回的知识库ID

**使用示例**:
```c
char *request_id = kb_generate_request_id();
if (request_id) {
    printf("生成的请求ID: %s\n", request_id);
    kb_free_string(request_id);  // 释放内存
    request_id = NULL;           // 避免悬挂指针
}
```

#### 2.4.2 字符串数组内存释放

```c
void kb_free_string_array(char **str_array, int count);
```

**功能**: 释放SDK返回的字符串数组内存
**参数**:
- `str_array`: 字符串数组指针（可以为NULL）
- `count`: 数组中字符串的数量
**返回**: 无
**线程安全**: 是

**使用场景**:
- 释放`kb_document_list()`返回的文档ID数组
- 释放`kb_document_process_multi()`返回的文档ID数组

**使用示例**:
```c
int doc_count;
char **doc_ids = kb_document_list(session, kb_id, &doc_count, &error);
if (doc_ids) {
    for (int i = 0; i < doc_count; i++) {
        printf("文档 %d: %s\n", i+1, doc_ids[i]);
    }
    kb_free_string_array(doc_ids, doc_count);  // 释放整个数组

```

## 3. 会话管理

会话（Session）是SDK的核心概念，它代表了一个应用程序与知识库服务的连接实例。所有的知识库操作都必须通过有效的会话来执行。会话管理包括创建、初始化、配置和销毁等生命周期管理。

### 3.1 会话生命周期

```
创建会话 → 初始化 → 使用会话 → 销毁会话
   ↓         ↓        ↓        ↓
 CREATE    INIT     USE     DESTROY
```

#### 生命周期详解

1. **创建阶段**: 分配会话内存，注册应用程序，获取应用ID
2. **初始化阶段**: 建立网络连接，验证身份，准备服务
3. **使用阶段**: 执行知识库操作，处理请求响应
4. **销毁阶段**: 清理资源，关闭连接，释放内存

### 3.2 会话创建

```c
KBSession *kb_session_create(const char *app_name, const char *password, KBError *error_code);
```

**功能**: 创建新的知识库会话
**参数**:
- `app_name`: 应用程序名称（必需，1-64字符）
- `password`: 应用程序密码（必需，8-128字符）
- `error_code`: 错误码输出指针（可选）

**返回**:
- 成功：会话实例指针
- 失败：NULL，错误码通过`error_code`返回

**线程安全**: 是
**内存管理**: 调用者负责使用`kb_session_destroy()`释放

#### 详细说明

**应用程序名称要求**:
- 长度：1-64个字符
- 字符集：字母、数字、下划线、连字符
- 不能以数字开头
- 区分大小写

**密码要求**:
- 长度：8-128个字符
- 必须包含字母和数字
- 支持特殊字符：!@#$%^&*()_+-=[]{}|;:,.<>?

**错误码说明**:
- `KB_ERROR_INVALID_PARAM`: 参数无效（名称或密码不符合要求）
- `KB_ERROR_NETWORK_CONNECTION`: 无法连接到服务器
- `KB_ERROR_NETWORK_AUTHENTICATION`: 认证失败
- `KB_ERROR_INTERNAL`: 内部错误

#### 使用示例

```c
// 基本用法
KBError error;
KBSession *session = kb_session_create("MyApplication", "SecurePass123", &error);
if (!session) {
    switch (error) {
        case KB_ERROR_INVALID_PARAM:
            printf("应用名称或密码格式不正确\n");
            break;
        case KB_ERROR_NETWORK_CONNECTION:
            printf("无法连接到服务器，请检查网络\n");
            break;
        case KB_ERROR_NETWORK_AUTHENTICATION:
            printf("认证失败，请检查应用名称和密码\n");
            break;
        default:
            printf("创建会话失败: %s\n", kb_get_error_message(error));
    }
    return -1;
}

// 不关心具体错误码的用法
KBSession *session = kb_session_create("MyApp", "password", NULL);
if (!session) {
    printf("创建会话失败\n");
    return -1;
}
```

### 3.3 会话初始化

```c
KBError kb_session_init(KBSession *session);
```

**功能**: 初始化会话，建立服务连接
**参数**:
- `session`: 会话实例指针（必需，不能为NULL）

**返回**:
- `KB_SUCCESS`: 初始化成功
- 其他错误码：初始化失败

**线程安全**: 是
**前置条件**: 会话必须已通过`kb_session_create()`创建

#### 详细说明

初始化过程包括：
1. **连接验证**: 验证与服务器的连接状态
2. **服务发现**: 发现可用的知识库服务
3. **资源准备**: 准备内部缓存和工作线程
4. **配置加载**: 加载默认配置参数

**可能的错误**:
- `KB_ERROR_INVALID_PARAM`: 会话指针为NULL
- `KB_ERROR_SESSION_INVALID`: 会话已损坏或未正确创建
- `KB_ERROR_NETWORK_TIMEOUT`: 网络超时
- `KB_ERROR_INITIALIZATION`: 初始化失败

#### 使用示例

```c
KBError error = kb_session_init(session);
if (error != KB_SUCCESS) {
    printf("初始化会话失败: %s\n", kb_get_error_message(error));
    kb_session_destroy(session);
    return -1;
}
printf("会话初始化成功\n");
```

### 3.4 会话销毁

```c
void kb_session_destroy(KBSession *session);
```

**功能**: 销毁会话并释放所有资源
**参数**:
- `session`: 会话实例指针（可以为NULL）

**返回**: 无
**线程安全**: 是
**幂等性**: 多次调用同一会话指针是安全的

#### 详细说明

销毁过程包括：
1. **停止活动**: 停止所有正在进行的操作
2. **清理缓存**: 清理内部缓存和临时数据
3. **关闭连接**: 关闭网络连接和文件句柄
4. **释放内存**: 释放所有分配的内存

**注意事项**:
- 调用后会话指针变为无效，不能再使用
- 正在进行的异步操作会被取消
- 相关的知识库对象和文档对象仍然有效

#### 使用示例

```c
// 基本用法
kb_session_destroy(session);
session = NULL;  // 避免悬挂指针

// 安全的销毁模式
void safe_destroy_session(KBSession **session) {
```

### 3.7 多会话管理

在复杂应用中，可能需要管理多个会话实例。

#### 会话池模式

```c
typedef struct {
    KBSession **sessions;
    int count;
    int capacity;
    pthread_mutex_t mutex;
} SessionPool;

SessionPool *session_pool_create(int capacity) {
    SessionPool *pool = malloc(sizeof(SessionPool));
    pool->sessions = calloc(capacity, sizeof(KBSession*));
    pool->count = 0;
    pool->capacity = capacity;
    pthread_mutex_init(&pool->mutex, NULL);
    return pool;
}

KBSession *session_pool_get(SessionPool *pool) {
    pthread_mutex_lock(&pool->mutex);
    KBSession *session = NULL;
    if (pool->count > 0) {
        session = pool->sessions[--pool->count];
    }
    pthread_mutex_unlock(&pool->mutex);
    return session;
}

void session_pool_put(SessionPool *pool, KBSession *session) {
    pthread_mutex_lock(&pool->mutex);
    if (pool->count < pool->capacity) {
        pool->sessions[pool->count++] = session;
    } else {
        kb_session_destroy(session);
    }
    pthread_mutex_unlock(&pool->mutex);
}
```

```c
KBSession *create_session_with_retry(const char *app_name, const char *password,
                                    int max_retries) {
    KBSession *session = NULL;
    KBError error;

    for (int i = 0; i < max_retries; i++) {
        session = kb_session_create(app_name, password, &error);

            error = kb_session_init(session);
            if (error == KB_SUCCESS) {
                return session;

            kb_session_destroy(session);
            session = NULL;

        if (error == KB_ERROR_NETWORK_TIMEOUT ||
            error == KB_ERROR_NETWORK_CONNECTION) {
            printf("重试 %d/%d...\n", i+1, max_retries);
            sleep(1);  // 等待1秒后重试
        } else {
            break;  // 其他错误不重试
        }
    }

    return NULL;
}
```

## 4. 知识库管理

知识库是文档和知识的容器，提供了文档的组织、存储和检索功能。每个知识库都有唯一的标识符，包含元数据信息如名称、描述、创建时间等。知识库管理包括创建、删除、查询、更新等操作。

### 4.1 知识库架构

```
知识库 (Knowledge Base)
├── 元数据 (Metadata)
│   ├── 知识库ID (KB ID)
│   ├── 名称 (Name)
│   ├── 描述 (Description)
│   ├── 创建时间 (Create Time)
│   └── 更新时间 (Update Time)
├── 文档集合 (Documents)
│   ├── 文档1 (Document 1)
│   ├── 文档2 (Document 2)
│   └── ...
├── 索引数据 (Index Data)
│   ├── 向量索引 (Vector Index)
│   ├── 全文索引 (Full-text Index)
│   └── 元数据索引 (Metadata Index)
└── 配置信息 (Configuration)
    ├── 分块策略 (Chunking Strategy)
    ├── 向量模型 (Vector Model)
    └── 检索参数 (Retrieval Parameters)
```

```c
            const char *id = kb_knowledgebase_info_get_id(kb_list[i]);

            printf("%d. %s (ID: %s)\n", ++matched, name, id);
            if (desc && strlen(desc) > 0) {
                printf("   描述: %s\n", desc);
            }
        }
    }

    if (matched == 0) {
        printf("没有找到匹配的知识库\n");
    }

    kb_knowledgebase_info_array_free(kb_list, count);
}
```

## 5. 文档处理

文档处理是知识库系统的核心功能，负责将各种格式的文档转换为可搜索的知识条目。处理过程包括文档解析、内容提取、智能分块、向量化和索引建立等多个阶段。

### 5.1 文档处理流程

```
文档上传 → 格式检测 → 内容解析 → 智能分块 → 向量化 → 索引建立 → 完成
   ↓         ↓         ↓        ↓        ↓        ↓       ↓
 UPLOAD   DETECT    PARSE    CHUNK   VECTORIZE INDEX  COMPLETE
                                ↓
                          如果任何阶段失败 → ERROR
```

#### 处理阶段详解

1. **格式检测**: 自动识别文档格式（PDF、DOC、TXT等）
2. **内容解析**: 提取文本、图片、表格等内容
3. **智能分块**: 根据语义和结构进行智能分块
4. **向量化**: 将文本转换为向量表示
5. **索引建立**: 建立向量索引和全文索引
6. **元数据存储**: 存储文档元数据和处理结果

### 5.2 支持的文档格式

| 格式 | 扩展名 | 支持程度 | 特殊功能 |
|------|--------|----------|----------|
| PDF | .pdf | 完全支持 | 文本提取、图片识别、表格解析 |
| Word | .doc, .docx | 完全支持 | 样式保留、表格处理、图片提取 |
| Excel | .xls, .xlsx | 完全支持 | 表格数据、公式解析、图表处理 |
| PowerPoint | .ppt, .pptx | 完全支持 | 幻灯片内容、备注提取 |
| 纯文本 | .txt | 完全支持 | 编码自动检测、换行处理 |
| Markdown | .md | 完全支持 | 格式解析、代码块处理 |
| HTML | .html, .htm | 完全支持 | 标签过滤、链接提取 |
| RTF | .rtf | 基本支持 | 富文本格式处理 |
| CSV | .csv | 基本支持 | 数据表格处理 |

```c
// 目录批量处理函数
char **process_directory(KBSession *session, const char *kb_id, const char *dir_path) {
    DIR *dir = opendir(dir_path);
    if (!dir) {
        printf("无法打开目录: %s\n", dir_path);
        return NULL;
    }

    // 收集文档文件
    char **file_paths = NULL;
    int file_count = 0;
    int capacity = 100;

    file_paths = malloc(capacity * sizeof(char*));

    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL) {
        if (entry->d_type == DT_REG) {  // 普通文件
            char *ext = strrchr(entry->d_name, '.');
            if (ext && (strcmp(ext, ".pdf") == 0 ||
                       strcmp(ext, ".docx") == 0 ||
                       strcmp(ext, ".txt") == 0)) {

                if (file_count >= capacity) {
                    capacity *= 2;
                    file_paths = realloc(file_paths, capacity * sizeof(char*));
                }

                char *full_path = malloc(strlen(dir_path) + strlen(entry->d_name) + 2);
                sprintf(full_path, "%s/%s", dir_path, entry->d_name);
                file_paths[file_count++] = full_path;
            }
        }
    }
    closedir(dir);

    if (file_count == 0) {
        printf("目录中没有找到支持的文档文件\n");
        free(file_paths);
        return NULL;
    }

    // 批量处理
    KBError error;
    char **doc_ids = kb_document_process_multi(session, kb_id,
                                              (const char**)file_paths,
                                              file_count, NULL, &error);

    // 清理文件路径
    for (int i = 0; i < file_count; i++) {
        free(file_paths[i]);
    }
    free(file_paths);

    if (!doc_ids) {
        printf("批量处理失败: %s\n", kb_get_error_message(error));
    }

    return doc_ids;
}
```

## 6. 聊天功能

聊天功能是知识库系统的核心应用，它基于知识库中的文档内容，通过AI模型为用户提供智能问答服务。支持流式响应、多轮对话、上下文理解和源文档引用等高级功能。

### 6.1 聊天架构

```
用户问题 → 问题理解 → 知识检索 → 上下文构建 → AI推理 → 流式响应
   ↓         ↓         ↓        ↓        ↓        ↓
QUESTION  UNDERSTAND RETRIEVE CONTEXT  INFER   STREAM
                                ↓
                        引用源文档 → 可信度评分
```

#### 处理流程详解

1. **问题理解**: 分析用户问题的意图和关键信息
2. **知识检索**: 从知识库中检索相关文档片段
3. **上下文构建**: 结合历史对话构建完整上下文
4. **AI推理**: 使用AI模型生成回答
5. **流式响应**: 实时返回生成的回答内容
6. **源文档引用**: 标注回答来源和可信度

### 6.2 流式聊天回调

```c
typedef int (*KBChatStreamCallback)(const KBChatResponse *response, void *user_data);
```

**功能**: 流式聊天响应的回调函数类型
**参数**:
- `response`: 当前响应块（包含增量内容）

**返回**:

- 非0: 停止流式传输

**调用频率**: 通常每100-200毫秒调用一次
**线程安全**: 回调函数需要是线程安全的

#### 回调函数设计原则

1. **快速处理**: 回调函数应该快速执行，避免阻塞
2. **错误处理**: 妥善处理异常情况
3. **状态管理**: 正确管理用户数据状态
4. **内存安全**: 不要保存response指针，其生命周期有限

#### 回调函数示例

```c
// 基本回调函数
int simple_chat_callback(const KBChatResponse *response, void *user_data) {
    if (!response) return 1;  // 停止传输

    const KBChatResult *result = kb_chat_response_get_result(response);
    if (result) {
        const char *text = kb_chat_result_get_response(result);
        if (text && strlen(text) > 0) {
            printf("%s", text);
            fflush(stdout);
        }
    }

    return 0;  // 继续传输
}

// 带状态管理的回调函数
typedef struct {
    FILE *log_file;
    int char_count;
    bool stop_requested;
} ChatCallbackData;

int advanced_chat_callback(const KBChatResponse *response, void *user_data) {
    ChatCallbackData *data = (ChatCallbackData*)user_data;

    if (!response || !data) return 1;

    // 检查是否请求停止
    if (data->stop_requested) {
        return 1;
    }

    // 检查错误
    int error_code = kb_chat_response_get_error_code(response);
    if (error_code != KB_SUCCESS) {
        printf("聊天错误: %s\n", kb_get_error_message(error_code));
        return 1;
    }

    const KBChatResult *result = kb_chat_response_get_result(response);
    if (result) {
        const char *text = kb_chat_result_get_response(result);
        if (text && strlen(text) > 0) {
            // 显示文本
            printf("%s", text);
            fflush(stdout);

            // 记录日志
            if (data->log_file) {
                fprintf(data->log_file, "%s", text);
                fflush(data->log_file);
            }

            // 更新字符计数
            data->char_count += strlen(text);

            // 检查是否达到最大长度
            if (data->char_count > 10000) {
                printf("\n[回答过长，已截断]\n");
                return 1;
            }
        }

        // 检查是否完成
        if (kb_chat_result_is_finished(result)) {
            printf("\n[回答完成]\n");

            // 显示源文档
            int source_count;
            const KBChatSource **sources = kb_chat_result_get_source(result, &source_count);
            if (sources && source_count > 0) {
                printf("\n参考文档:\n");
                for (int i = 0; i < source_count; i++) {
                    const char *file_id = kb_chat_source_get_file_id(sources[i]);
                    double confidence = kb_chat_source_get_confidence(sources[i]);
                    printf("  %d. %s (可信度: %.2f)\n", i+1, file_id, confidence);
                }
            }

            return 1;  // 完成后停止
        }
    }

    return 0;  // 继续传输
}

// 信号处理回调（支持Ctrl+C中断）
static volatile bool g_stop_chat = false;

void signal_handler(int signal) {
    if (signal == SIGINT) {
        g_stop_chat = true;
        printf("\n[用户中断聊天]\n");
    }
}

int interruptible_chat_callback(const KBChatResponse *response, void *user_data) {
    if (g_stop_chat) {
        return 1;  // 用户中断
    }

    // 其他处理逻辑...
    return simple_chat_callback(response, user_data);
}
```

```c
    // 设置为连续对话模式
    kb_chat_config_set_new_chat(config, false);

    printf("知识库聊天系统 (输入 'quit' 退出)\n");
    printf("=================================\n");

    while (true) {
        printf("\n用户: ");
        fflush(stdout);

        if (!fgets(question, sizeof(question), stdin)) {
            break;
        }

        // 移除换行符
        char *newline = strchr(question, '\n');
        if (newline) *newline = '\0';

        // 检查退出命令
        if (strcmp(question, "quit") == 0 || strcmp(question, "exit") == 0) {
            break;
        }

        if (strlen(question) == 0) {
            continue;
        }

        printf("AI: ");
        fflush(stdout);

        signal(SIGINT, signal_handler);
        g_stop_chat = false;

        KBError error = kb_chat_stream(
            session,
            NULL,
            kb_id,
            question,

            interruptible_chat_callback,
            NULL
        );

        if (error != KB_SUCCESS) {
```

```c
// 超时停止机制
typedef struct {
    KBSession *session;
    char *request_id;
    int timeout_seconds;
    bool completed;
} ChatTimeoutData;

void *timeout_thread(void *arg) {
    ChatTimeoutData *data = (ChatTimeoutData*)arg;

    sleep(data->timeout_seconds);

    if (!data->completed) {
        printf("\n[聊天超时，正在停止...]\n");
        kb_chat_stream_stop(data->session, data->request_id);
    }

    return NULL;
}

int timeout_callback(const KBChatResponse *response, void *user_data) {
    ChatTimeoutData *data = (ChatTimeoutData*)user_data;

    // 检查是否完成
    const KBChatResult *result = kb_chat_response_get_result(response);
    if (result && kb_chat_result_is_finished(result)) {
        data->completed = true;
    }

    return simple_chat_callback(response, NULL);
}

void chat_with_timeout(KBSession *session, const char *kb_id, const char *question, int timeout) {
    char *request_id = kb_generate_request_id();

    ChatTimeoutData timeout_data = {
        .session = session,
        .request_id = request_id,
        .timeout_seconds = timeout,
        .completed = false
    };

    // 启动超时线程
    pthread_t timeout_thread_id;
    pthread_create(&timeout_thread_id, NULL, timeout_thread, &timeout_data);

    // 启动聊天
    KBError error = kb_chat_stream(session, request_id, kb_id, question, NULL, timeout_callback, &timeout_data);

    if (error == KB_SUCCESS) {
        // 等待完成或超时
        pthread_join(timeout_thread_id, NULL);
    }

    kb_free_string(request_id);
}
```

```c
    int folder_count;

    SearchScope *scope = malloc(sizeof(SearchScope));
    scope->doc_ids = NULL;
    scope->doc_count = 0;
    scope->folder_ids = NULL;
    scope->folder_count = 0;
    return scope;
}

void add_doc_to_scope(SearchScope *scope, const char *doc_id) {
    scope->doc_ids = realloc(scope->doc_ids, (scope->doc_count + 1) * sizeof(char*));
    scope->doc_ids[scope->doc_count] = strdup(doc_id);
    scope->doc_count++;
}

void add_folder_to_scope(SearchScope *scope, const char *folder_id) {
    scope->folder_ids = realloc(scope->folder_ids, (scope->folder_count + 1) * sizeof(char*));
    scope->folder_ids[scope->folder_count] = strdup(folder_id);
    scope->folder_count++;
}

void apply_search_scope(KBChatConfig *config, SearchScope *scope) {
    if (scope->doc_count > 0) {
        kb_chat_config_set_doc_ids(config, (const char**)scope->doc_ids, scope->doc_count);
    }
    if (scope->folder_count > 0) {
        kb_chat_config_set_folder_ids(config, (const char**)scope->folder_ids, scope->folder_count);
    }
}

void free_search_scope(SearchScope *scope) {
    if (scope) {
        for (int i = 0; i < scope->doc_count; i++) {
            free(scope->doc_ids[i]);
        }
        free(scope->doc_ids);

        for (int i = 0; i < scope->folder_count; i++) {
            free(scope->folder_ids[i]);
        }
        free(scope->folder_ids);

        free(scope);
    }
```

```c
// 完整的响应处理回调
int comprehensive_response_handler(const KBChatResponse *response, void *user_data) {
    if (!response) {
        printf("响应对象为空\n");
        return 1;
    }

    // 获取基本信息
    const char *chat_id = kb_chat_response_get_chat_id(response);
    const char *request_id = kb_chat_response_get_request_id(response);
    int error_code = kb_chat_response_get_error_code(response);

    printf("会话ID: %s\n", chat_id ? chat_id : "未知");
    printf("请求ID: %s\n", request_id ? request_id : "未知");

    // 检查错误
    if (error_code != KB_SUCCESS) {
        printf("聊天错误: %s (错误码: %d)\n",
               kb_get_error_message(error_code), error_code);
        return 1;  // 停止处理
    }

    // 获取结果
    const KBChatResult *result = kb_chat_response_get_result(response);
    if (!result) {
        printf("无法获取聊天结果\n");
        return 1;
    }

    // 处理结果内容
    const char *question = kb_chat_result_get_question(result);
    const char *answer = kb_chat_result_get_response(result);
    bool is_finished = kb_chat_result_is_finished(result);

    if (question) {
        printf("问题: %s\n", question);
    }

    if (answer && strlen(answer) > 0) {
        printf("回答: %s", answer);
        if (!is_finished) {
            printf(" [继续中...]");
        }
        printf("\n");
    }

    // 处理源文档
    if (is_finished) {
        int source_count;
        const KBChatSource **sources = kb_chat_result_get_source(result, &source_count);

        if (sources && source_count > 0) {
            printf("\n参考来源:\n");
            for (int i = 0; i < source_count; i++) {
                const char *file_id = kb_chat_source_get_file_id(sources[i]);
                const char *content = kb_chat_source_get_content(sources[i]);
                double confidence = kb_chat_source_get_confidence(sources[i]);

                printf("  %d. 文件: %s (可信度: %.2f%%)\n",
                       i+1, file_id, confidence * 100);

                if (content && strlen(content) > 0) {
                    printf("     内容: %.100s%s\n",
                           content, strlen(content) > 100 ? "..." : "");
                }
            }
        }

        return 1;  // 完成后停止
    }

    return 0;  // 继续接收
}
```

```c
    const char *question = kb_chat_result_get_question(result);

        while (token) {

                avg_confidence += kb_chat_source_get_confidence(sources[i]);

// 增量内容累积
typedef struct {
    char *accumulated_response;
    size_t buffer_size;
    size_t current_length;
} ResponseAccumulator;

ResponseAccumulator *create_accumulator() {
    ResponseAccumulator *acc = malloc(sizeof(ResponseAccumulator));
    acc->buffer_size = 1024;
    acc->accumulated_response = malloc(acc->buffer_size);
    acc->accumulated_response[0] = '\0';
    acc->current_length = 0;
    return acc;
}

void accumulate_response(ResponseAccumulator *acc, const char *new_content) {
    if (!acc || !new_content) return;

    size_t new_length = strlen(new_content);
    size_t needed_size = acc->current_length + new_length + 1;

    if (needed_size > acc->buffer_size) {
        acc->buffer_size = needed_size * 2;  // 预留空间
        acc->accumulated_response = realloc(acc->accumulated_response, acc->buffer_size);
    }

    strcat(acc->accumulated_response, new_content);
    acc->current_length += new_length;
}

void free_accumulator(ResponseAccumulator *acc) {
    if (acc) {
        free(acc->accumulated_response);
        free(acc);
    }
}

int accumulating_callback(const KBChatResponse *response, void *user_data) {
    ResponseAccumulator *acc = (ResponseAccumulator*)user_data;

    if (!response || !acc) return 1;

    const KBChatResult *result = kb_chat_response_get_result(response);
    if (!result) return 1;

    const char *new_content = kb_chat_result_get_response(result);
    if (new_content && strlen(new_content) > 0) {
        accumulate_response(acc, new_content);
        printf("%s", new_content);  // 实时显示
        fflush(stdout);
    }

    if (kb_chat_result_is_finished(result)) {
        printf("\n\n完整回答:\n%s\n", acc->accumulated_response);
        return 1;
    }

    return 0;
}
```

```c
// 源文档详细分析
void analyze_sources(const KBChatSource **sources, int count) {
    if (!sources || count <= 0) {
        printf("没有源文档信息\n");
        return;
    }

    printf("源文档分析 (共 %d 个):\n", count);
    printf("%-20s %-10s %-50s\n", "文件ID", "可信度", "内容预览");
    printf("%-20s %-10s %-50s\n", "------", "------", "--------");

    for (int i = 0; i < count; i++) {
        const char *file_id = kb_chat_source_get_file_id(sources[i]);
        const char *content = kb_chat_source_get_content(sources[i]);
        double confidence = kb_chat_source_get_confidence(sources[i]);

        // 截取内容预览
        char preview[51] = {0};
        if (content) {
            strncpy(preview, content, 50);
            if (strlen(content) > 50) {
                strcpy(preview + 47, "...");
            }
        }

        printf("%-20s %8.2f%% %-50s\n",
               file_id ? file_id : "未知",
               confidence * 100,
               preview);
    }

    // 统计信息
    double total_confidence = 0.0;
    int high_confidence_count = 0;

    for (int i = 0; i < count; i++) {
        double conf = kb_chat_source_get_confidence(sources[i]);
        total_confidence += conf;
        if (conf >= 0.8) {
            high_confidence_count++;
        }
    }

    printf("\n统计信息:\n");
    printf("  平均可信度: %.2f%%\n", (total_confidence / count) * 100);
    printf("  高可信度源: %d/%d\n", high_confidence_count, count);
}

// 源文档过滤和排序
typedef struct {
    const KBChatSource *source;
    int original_index;
} SourceWithIndex;

int compare_sources_by_confidence(const void *a, const void *b) {
    const SourceWithIndex *sa = (const SourceWithIndex*)a;
    const SourceWithIndex *sb = (const SourceWithIndex*)b;

    double conf_a = kb_chat_source_get_confidence(sa->source);
    double conf_b = kb_chat_source_get_confidence(sb->source);

    if (conf_a < conf_b) return 1;
    if (conf_a > conf_b) return -1;
    return 0;
}

void display_filtered_sources(const KBChatSource **sources, int count, double min_confidence) {
    if (!sources || count <= 0) return;

    // 创建带索引的源数组
    SourceWithIndex *indexed_sources = malloc(count * sizeof(SourceWithIndex));
    int filtered_count = 0;

    for (int i = 0; i < count; i++) {
        double conf = kb_chat_source_get_confidence(sources[i]);
        if (conf >= min_confidence) {
            indexed_sources[filtered_count].source = sources[i];
            indexed_sources[filtered_count].original_index = i;
            filtered_count++;
        }
    }

    if (filtered_count == 0) {
        printf("没有满足可信度要求(%.2f%%)的源文档\n", min_confidence * 100);
        free(indexed_sources);
        return;
    }

    // 按可信度排序
    qsort(indexed_sources, filtered_count, sizeof(SourceWithIndex), compare_sources_by_confidence);

    printf("高可信度源文档 (可信度 >= %.2f%%):\n", min_confidence * 100);

    for (int i = 0; i < filtered_count; i++) {
        const KBChatSource *source = indexed_sources[i].source;
        const char *file_id = kb_chat_source_get_file_id(source);
        const char *content = kb_chat_source_get_content(source);
        double confidence = kb_chat_source_get_confidence(source);

        printf("\n%d. 文件: %s (可信度: %.2f%%)\n",
               i+1, file_id, confidence * 100);

        if (content) {
            printf("   内容: %s\n", content);
        }
    }

    free(indexed_sources);
}
```

```c
    if (timestamp) {
        strftime(timestamp, 20, "%Y%m%d_%H%M%S", tm_info);
    }

    return timestamp;
}
```

```c
// 收集目录中的文档文件
char **collect_documents(const char *dir_path, int *count) {
    DIR *dir = opendir(dir_path);
    if (!dir) {
        printf("无法打开目录: %s\n", dir_path);
        return NULL;
    }

    char **files = NULL;
    int file_count = 0;
    int capacity = 100;

    files = malloc(capacity * sizeof(char*));

    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL) {
        if (entry->d_type == DT_REG) {  // 普通文件
            char full_path[4096];
            snprintf(full_path, sizeof(full_path), "%s/%s", dir_path, entry->d_name);

            if (is_supported_format(full_path)) {
                if (file_count >= capacity) {
                    capacity *= 2;
                    files = realloc(files, capacity * sizeof(char*));
                }

                files[file_count++] = strdup(full_path);
            }
        }
    }

    closedir(dir);
    *count = file_count;
    return files;
}
```

```c
            size_t text_len = strlen(text);
            size_t needed_size = req->response_length + text_len + 1;

            }

            strcat(req->response_buffer, text);
            req->response_length += text_len;

            return 1;
        }

// 处理聊天请求
int handle_chat_request(void *cls, struct MHD_Connection *connection,
                       const char *url, const char *method,
                       const char *version, const char *upload_data,
                       size_t *upload_data_size, void **con_cls) {

    WebServiceConfig *config = (WebServiceConfig*)cls;

    if (strcmp(method, "POST") != 0) {
        const char *error_response = "{\"error\": \"Method not allowed\"}";
        struct MHD_Response *response = MHD_create_response_from_buffer(
            strlen(error_response), (void*)error_response, MHD_RESPMEM_PERSISTENT);
        MHD_add_response_header(response, "Content-Type", "application/json");
        int ret = MHD_queue_response(connection, MHD_HTTP_METHOD_NOT_ALLOWED, response);
        MHD_destroy_response(response);
        return ret;
    }

    if (strcmp(url, "/chat") != 0) {
        const char *error_response = "{\"error\": \"Not found\"}";
        struct MHD_Response *response = MHD_create_response_from_buffer(
            strlen(error_response), (void*)error_response, MHD_RESPMEM_PERSISTENT);
        MHD_add_response_header(response, "Content-Type", "application/json");
        int ret = MHD_queue_response(connection, MHD_HTTP_NOT_FOUND, response);
        MHD_destroy_response(response);
        return ret;
    }

    // 解析JSON请求
    json_object *json_req = json_tokener_parse(upload_data);
    if (!json_req) {
        const char *error_response = "{\"error\": \"Invalid JSON\"}";
        struct MHD_Response *response = MHD_create_response_from_buffer(
            strlen(error_response), (void*)error_response, MHD_RESPMEM_PERSISTENT);
        MHD_add_response_header(response, "Content-Type", "application/json");
        int ret = MHD_queue_response(connection, MHD_HTTP_BAD_REQUEST, response);
        MHD_destroy_response(response);
        return ret;
    }

    // 提取请求参数
    json_object *question_obj, *model_obj, *new_chat_obj;
    json_object_object_get_ex(json_req, "question", &question_obj);
    json_object_object_get_ex(json_req, "model", &model_obj);
    json_object_object_get_ex(json_req, "new_chat", &new_chat_obj);

    const char *question = json_object_get_string(question_obj);
    const char *model = model_obj ? json_object_get_string(model_obj) : "gpt-3.5-turbo";
    bool new_chat = new_chat_obj ? json_object_get_boolean(new_chat_obj) : true;

    if (!question || strlen(question) == 0) {
        json_object_put(json_req);
        const char *error_response = "{\"error\": \"Question is required\"}";
        struct MHD_Response *response = MHD_create_response_from_buffer(
            strlen(error_response), (void*)error_response, MHD_RESPMEM_PERSISTENT);
        MHD_add_response_header(response, "Content-Type", "application/json");
        int ret = MHD_queue_response(connection, MHD_HTTP_BAD_REQUEST, response);
        MHD_destroy_response(response);
        return ret;
    }

    // 创建聊天请求
    ChatRequest chat_req = {
        .question = strdup(question),
        .model = strdup(model),
        .new_chat = new_chat,
        .response_buffer = malloc(1024),
        .buffer_size = 1024,
        .response_length = 0,
        .completed = false
    };
    chat_req.response_buffer[0] = '\0';

    // 配置聊天
    KBChatConfig *chat_config = kb_chat_config_new();
    kb_chat_config_set_new_chat(chat_config, new_chat);
    kb_chat_config_set_model(chat_config, model);

    // 执行聊天
    KBError error = kb_chat_stream(config->session, NULL, config->kb_id,
                                  question, chat_config, web_chat_callback, &chat_req);

    // 等待完成
    while (!chat_req.completed && error == KB_SUCCESS) {
        usleep(100000);  // 100ms
    }

    // 构建JSON响应
    json_object *json_resp = json_object_new_object();

    if (error == KB_SUCCESS && chat_req.completed) {
        json_object *success_obj = json_object_new_boolean(true);
        json_object *response_obj = json_object_new_string(chat_req.response_buffer);

        json_object_object_add(json_resp, "success", success_obj);
        json_object_object_add(json_resp, "response", response_obj);

        json_object *error_obj = json_object_new_string(kb_get_error_message(error));

        json_object_object_add(json_resp, "success", success_obj);
        json_object_object_add(json_resp, "error", error_obj);

    struct MHD_Response *response = MHD_create_response_from_buffer(
        strlen(response_str), (void*)response_str, MHD_RESPMEM_MUST_COPY);

    MHD_add_response_header(response, "Content-Type", "application/json");
    MHD_add_response_header(response, "Access-Control-Allow-Origin", "*");

        printf("❌ 初始化会话失败: %s\n", kb_get_error_message(error));
        kb_session_destroy(session);
        return 1;
    }

    // 配置Web服务
    WebServiceConfig config = {
        .session = session,
        .kb_id = strdup(kb_id),
        .port = port
    };

    // 启动HTTP服务器
    struct MHD_Daemon *daemon = MHD_start_daemon(
        MHD_USE_THREAD_PER_CONNECTION,
        port,
        NULL, NULL,
        &handle_chat_request, &config,
        MHD_OPTION_END
    );

    if (!daemon) {
        printf("❌ 启动HTTP服务器失败\n");
        free(config.kb_id);
        kb_session_destroy(session);
        return 1;
    }

    printf("✅ Web服务启动成功，端口: %d\n", port);
    printf("📡 API端点: http://localhost:%d/chat\n", port);
    printf("按 Enter 键停止服务...\n");

    getchar();

    // 停止服务
    MHD_stop_daemon(daemon);
    free(config.kb_id);
    kb_session_destroy(session);

    printf("👋 Web服务已停止\n");
    return 0;
}
```

```c
typedef struct {
    KBSession **sessions;
    int count;
    int capacity;
    pthread_mutex_t mutex;
    pthread_cond_t cond;
} SessionPool;

SessionPool *create_session_pool(int capacity, const char *app_name, const char *password) {
    SessionPool *pool = malloc(sizeof(SessionPool));
    pool->sessions = malloc(capacity * sizeof(KBSession*));
    pool->count = 0;
    pool->capacity = capacity;
    pthread_mutex_init(&pool->mutex, NULL);
    pthread_cond_init(&pool->cond, NULL);

    // 预创建会话
    for (int i = 0; i < capacity; i++) {
        KBError error;
        KBSession *session = kb_session_create(app_name, password, &error);
        if (session && kb_session_init(session) == KB_SUCCESS) {
            pool->sessions[pool->count++] = session;
        }
    }

    return pool;
}

KBSession *get_session_from_pool(SessionPool *pool) {
    pthread_mutex_lock(&pool->mutex);

    while (pool->count == 0) {
        pthread_cond_wait(&pool->cond, &pool->mutex);
    }

    KBSession *session = pool->sessions[--pool->count];
    pthread_mutex_unlock(&pool->mutex);

    return session;
}

void return_session_to_pool(SessionPool *pool, KBSession *session) {
    pthread_mutex_lock(&pool->mutex);

    if (pool->count < pool->capacity) {
        pool->sessions[pool->count++] = session;
        pthread_cond_signal(&pool->cond);
    } else {
        kb_session_destroy(session);
    }

    pthread_mutex_unlock(&pool->mutex);
}

void optimize_batch_processing(KBSession *session, const char *kb_id,
                              char **doc_paths, int doc_count) {

    // 按文件大小排序，小文件先处理
    qsort(doc_paths, doc_count, sizeof(char*), compare_by_file_size);

    // 分批处理，避免内存压力
    int batch_size = 10;
    for (int i = 0; i < doc_count; i += batch_size) {
        int current_batch = (i + batch_size > doc_count) ? doc_count - i : batch_size;

        char **doc_ids = kb_document_process_multi(session, kb_id,
                                                  (const char**)(doc_paths + i),
                                                  current_batch, NULL, NULL);

        if (doc_ids) {
            // 等待当前批次完成

            kb_free_string_array(doc_ids, current_batch);
        }

        // 短暂休息，避免过载
        usleep(100000);  // 100ms
    }

typedef struct {
    char *question;
    char *answer;
    time_t timestamp;
    double confidence;
} CacheEntry;

typedef struct {
    CacheEntry *entries;
    int count;
    int capacity;
    pthread_rwlock_t rwlock;
} QuestionCache;

QuestionCache *create_cache(int capacity) {
    QuestionCache *cache = malloc(sizeof(QuestionCache));
    cache->entries = malloc(capacity * sizeof(CacheEntry));
    cache->count = 0;
    cache->capacity = capacity;
    pthread_rwlock_init(&cache->rwlock, NULL);
    return cache;
}

char *search_cache(QuestionCache *cache, const char *question) {
    pthread_rwlock_rdlock(&cache->rwlock);

    for (int i = 0; i < cache->count; i++) {
        if (strcmp(cache->entries[i].question, question) == 0) {
            // 检查缓存是否过期（例如1小时）
            if (time(NULL) - cache->entries[i].timestamp < 3600) {
                char *answer = strdup(cache->entries[i].answer);
                pthread_rwlock_unlock(&cache->rwlock);
                return answer;
            }
        }
    }

    pthread_rwlock_unlock(&cache->rwlock);
    return NULL;
}

void add_to_cache(QuestionCache *cache, const char *question, const char *answer) {
    pthread_rwlock_wrlock(&cache->rwlock);

    // 如果缓存满了，删除最旧的条目
    if (cache->count >= cache->capacity) {
        free(cache->entries[0].question);
        free(cache->entries[0].answer);
        memmove(&cache->entries[0], &cache->entries[1],
                (cache->count - 1) * sizeof(CacheEntry));
        cache->count--;
    }

    // 添加新条目
    cache->entries[cache->count].question = strdup(question);
    cache->entries[cache->count].answer = strdup(answer);
    cache->entries[cache->count].timestamp = time(NULL);
    cache->count++;

    pthread_rwlock_unlock(&cache->rwlock);
}
```
