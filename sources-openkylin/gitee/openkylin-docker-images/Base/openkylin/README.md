# Tags
The version numbers of openKylin are used as the tags,  such as 2.0 and 3.0.
## Special tags
- `2.0` or `3.0` represents the recommended version of respective `LTS` series.
- `latest` is the latest recommended version.
## Supported tags
- `3.0, latest`
- `2.0`
