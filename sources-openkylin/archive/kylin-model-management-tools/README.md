# 麒麟 AI 模型管理工具

麒麟 AI 模型管理工具可以自动下载自然语言处理、语音识别和文本检索等本地大模型。性能不错的机器可以使用本地大模型体验 AI 助手。

## 工具获取

麒麟模型管理工具包名是`kylin-model-management-tools`，新的 openKylin 系统中已经默认集成了此包。若你的系统中还没有，可以 执行`sudo apt install kylin-model-management-tools`进行安装。

## 工具使用

### 工具启动

在终端中执行`kylin-model-downloader`或者在开始菜单中打开`麒麟模型管理工具`。（名称可能会有变化）

### 模型下载

当前支持的模型有三种，分别用于自然语言处理、语音识别和文本检索。

#### 一键下载

模型管理工具支持一键下载，只需点击`一键下载`按钮，然后输入管理员密码即可。

#### 高级下载

用户也可以自行选择下载的模型。

 - `自然语言处理`模型只有一个：
    1. 在`模型类型`处选择`nlp`；
    2. 点击`下载模型`按钮即可；

 - `语音识别`模型有 4 个：
    1. 在`模型类型`处选择`speech`；
    2. 在`模型名称`处选择一个模型；
    3. 点击`下载模型`按钮即可；
    4. 重复 2 和 3 直到下载完成所有`speech`模型；

 - `文本检索`模型有 2 个：
    1. 在`模型类型`处选择`搜索`；
    2. 在`模型名称`处选择一个模型；
    3. 点击`下载模型`按钮即可；
    4. 重复 2 和 3 直到下载完成所有`搜索`模型；

### 模型检查

工具中有一个`检查本地模型文件`按钮，用于检查下载模型的完整性。如果所有模型均存在且文件正确，则输出全为成功；若输出有失败，请重新下载对应模型。

### 工具退出

模型下载成功后，工具可以退出。

## 注意

1. 模型下载需要连接**可以访问`https://www.modelscope.cn/`的网络**。
2. 初次下载模型时，需要先下载一些依赖，时间可能较长，请耐心等待。
