### Audio
Set up the output, input, system sound effects and advanced Settings as shown in the figure.

![Fig 3 Audio-output-big](image/audio1.png)

- Output Device: Obtain the output device generated by the output configuration file selected by the sound card, and switch to the corresponding output device as needed.
- Master Volume: Adjust the current output volume by moving the slider to control the size of the system output volume.
- Volume Increase: When volume increase is enabled, the adjustable range of volume changes from 0-100% to 0-125%.
- Balance: The function of adjusting the volume ratio of the left and right channels in the output volume, allowing listeners at different positions to hear a balanced and harmonious sound.
- Mono audio: A sound is played through an audio signal channel. It sounds as if the sound comes from the same direction, with no positional difference between the left and right channels.

![Fig 3 Audio-input-big](image/audio2.png)

- Input Device: The input device generated by the input configuration file selected by the sound card can be switched to the corresponding input device as needed (the input device is mainly used for recording videos, audio, and making calls).
- Volume: Adjust the current input volume by moving the slider to control the size of the system input volume.
- Input Level: A function that detects the strength of the audio signal received by the current input device, helping users determine if the input volume is appropriate and avoiding excessive distortion or low clarity (it starts to detect the input level when an available input device is detected).
- Noise Reduction: The function of actively identifying and weakening useless noise in the environment through technology while retaining human voices or target sounds.
- Voice Monitor: You can hear your voice in the output device of your choice.

![Fig 3 Audio-tone-big](image/audio3.png)

- Startup: Whether the startup music is played when the control system is turned on.
- Shutdown: Whether the shutdown music is played when the control system is shut down.
- Log out: Whether to play the logout music when the control system is logged out.
- wake-up: whether to play wake-up music when the control system wakes up.
- Prompt tone: The control system plays a prompt tone when it receives a notification or changes the volume.
- Sound effect theme: The sound theme of the system.
- Volume adjustment: The type of prompt tone played when adjusting the volume.
- Receiving notification: The type of prompt sound played when the system receives the notification.

![Fig 4 Audio-advancedSettings-big](image/audio4.png)

- When disconnecting the audio device, pause playback: When the control system disconnects the audio device, pause the audio and video that are currently playing.
- Sound device management: Display the available sound devices in the system, and disable or turn on the devices.
- Application Sound: Display the application that is using sound in the system, and adjust the volume of the application separately and set the input/output devices of the application.

### Vino
Control whether your desktop can be remotely accessed by turning on and off the local VNC/RDP service. 

- "Connect to your desktop remotely" is turned off by default
- "Remote connection protocol" contains VNC and RDP, VNC by default
- "Allow connection to control screen" is on by default and can be manipulated
- "You must confirm every visit for this machine"is disabled by default, and each access request needs to be answered
- "Require user to enter this password when using VNC" is on by default, and the password is not displayed in plaintext by default
- "Displays that allow remote access"can set displays that allow remote control
- "The number of remote clients allowed to connect"can set the maximum number of clients allowed for remote connections

**Safety Risk Warning**

When enabling the operating system's remote desktop and using the VNC connection protocol, simultaneously disabling both the remote access authentication switch and the access password verification switch poses an extremely high security risk: anyone within the external network who knows the local machine's remote address and port can bypass identity verification and establish a VNC remote connection directly, unauthorized control of the local machine's desktop, as well as access, modify, or copy all sensitive information such as business data, private files, account configurations, etc. The device is highly vulnerable to illegal intrusions, malicious operations, data leaks, ransomware implantation, and other security incidents. Once exploited by malicious attackers, it may lead to business disruptions, loss of critical data, information leakage, and even financial losses.

We strongly recommend that you ensure the remote access confirmation and access password verification functions remain continuously enabled, set high-strength remote access passwords, promptly disable the VNC remote desktop service when not necessary for operations, and guard against the risks of illegal remote intrusions.

### Maintain Mode

An immutable system is an operating system designed to be unchangeable and read-only, where users or administrators cannot modify the system core, such as installing software packages or third-party drivers. If users or administrators need to handle package installations and similar operations as conveniently as in a mutable system, they can enable maintain mode. By default, maintain mode is turned off.

![Fig 8-1 Default Settings for Operation and Maintain Mode](image/maintain-mode-close.png)

Turn on the maintain mode switch to enable maintain mode (the system needs to be restarted as prompted for the maintain mode to take effect). Once successfully enabled, a "Maintain Mode" watermark will be displayed by default in the lower right corner of the desktop.

![Fig 8-2 Operation and Maintain Mode Watermark](image/maintain-mode-watermask.png)

After enabling maintain mode, you will notice several additional configuration items on the interface:

**Allow to save the data of maintain mode:** When turning off maintain mode, if this option is enabled, data generated during maintain mode (such as installed software packages) will be preserved. If disabled, data from the maintenance period will not be saved, and the system will revert to its state before entering maintain mode.

**The Watermask of Maintain Mode:** Configure the style of the maintain mode watermark.

- **Color:** Set the color of the watermark.
- **Font:** Adjust the font size of the watermark.
- **Position:** Specify the position where the watermark appears.

![Fig 8-3 Operation and Maintain Mode Settings](image/maintain-mode-open.png)

After configuring the above settings, turn off the maintain mode switch to exit maintain mode (a system restart is required for the changes to take effect, as prompted).

### TouchScreen

The system supports multi-tasking, multi-scene desktop touch interaction, if your device supports touch function, you can use a variety of touch gestures for desktop operation.

- Drag: Move object position, or drag for batch operations, such as: move windows/files, check icons/text, etc

- Pinch : Press and hold the screen with two fingers to expand outward to zoom in on content, and pinch inward to zoom out content, e.g. web pages, images

## Account

### User Info

Manage and configure system users, allowing administrators to create users, delete users, and modify user information.

**Safety Risk Warning**

After enabling password-free or automatic login in the operating system, the device will bypass the authentication process and directly enter the system, posing significant security risks: if the device is lost, stolen, or accessed without permission by unauthorized personnel, all local data, files, account information, and private content can be directly accessed, leading to risks such as information leakage, data tampering, and financial loss. Additionally, this feature lowers the threshold for system access, making it easier for malicious programs or unauthorized intrusions to exploit, thereby increasing the likelihood of device attacks.

To ensure your information security, avoid enabling passwordless or automatic login features unless necessary. It is recommended to use strong authentication methods such as passwords or fingerprints to log in to the system, preventing potential security incidents if the device falls out of control.

### Kylin ID
Kylin ID is a unified identity management system provided by Kylin Software for its users, allowing users to access multiple Kylin software services through a single credential.

#### Opening method
"Start Menu" > "Settings" > "Account" > "Kylin ID"

![Fig 32-1 Kylin ID-big](image/kylin-id1.png)

#### Kylin ID Registration

If you have not registered a Kylin ID yet, please click the "**Register**" button in the login box to go to the Kylin ID center for account registration.

![Fig 32-2 Login Registration-big](image/kylin-id2.png)

#### Kylin ID login

If you have already registered a KylinID, you can log in using either your account password or WeChat QR code scanning. The login interface may vary across different system versions; please refer to the actual page displayed.

##### Password login

- Enter your account/phone number/email and password, then click the "**Send**" button. A sliding CAPTCHA will appear for verification;
- After successful verification, a verification code will be sent to your registered phone number/email. Enter the verification code received;
- Click "**Login**" to complete the KylinID login;
- You may choose whether to remember your password when logging in.

##### Scan the QR code on WeChat to log in

- Click on the QR code in the bottom right corner of the login box and use WeChat to scan and quickly log in;
- Note that if the WeChat account has not registered a Kylin ID before, you need to register and scan the code again to log in.

If you forget your password, click on the login box "**Forgot Password**" to go to the Kylin ID center and use either your phone number or email to retrieve your password.

#### Kylin ID homepage

After logging in with Kylin ID, the default homepage is shown in Figure 32-3. Users can bind their Kylin ID to their local terminal account and synchronize their cloud account data through this page.

![Fig 32-3 Homepage Interface-big](image/kylin-id3.png)

#### Linking Kylin ID with local terminal account

- Click the switch button on the right side of the "**Bind with Current User**" field on the homepage, and a local account password verification window will pop up;
- After verification, the binding can be successful. After successful binding, you can view all terminal devices that have been bound to the current Kylin ID in the "**Device Management**" field on the homepage.

After binding the Kylin ID with the current local account password, if you forget the local account password, you can retrieve the password corresponding to the current local account through the "**Forgot Password**" on the login page of the terminal.

#### Unbind Kylin ID from local terminal account

- After successfully binding the Kylin ID to the local account on the terminal, click the switch button on the right side of the "**Bind with Current User**" field on the homepage, and a password verification window for the current local account will pop up;
- After verification, the binding relationship between Kylin ID and the current local account can be released

#### Cloud account synchronizable items

- Desktop Background: Synchronize Desktop Background
- Lock screen and screensaver: synchronize screensaver wallpaper, screensaver sleep time, etc
- Font: Synchronize font settings
- Avatar: Synchronize system user avatar
- Taskbar: Synchronize taskbar position, size, etc
- Quick Launch Bar: Synchronize Taskbar Plugin Quick Launch Bar Related Settings
- Theme: Synchronize Theme Settings
- Mouse: Synchronize Mouse Settings
- Touchpad: If there is a touchpad, synchronize the touchpad interface settings
- Keyboard: Synchronize keyboard settings
- Time format: Synchronize time, not set one-to-one correspondence
- File Manager: Synchronize the settings of the file manager, excluding the top window settings
- Power Management: Synchronize settings for power related options

#### Instructions for use

- Log in to the cloud account with Kylin ID, and the first time you open it, it will be synchronized once by default. If there is a configuration file in the cloud, the cloud configuration will be downloaded and synchronized to the local account first. Otherwise, the local account configuration will be uploaded to the cloud.
- After logging into the cloud account, if the automatic synchronization button is turned on, users do not need to take any other actions. The cloud account will synchronize the local configuration to the cloud every 5 minutes, and the uploaded configuration can be synchronized across machines and users.
- Turning off the separate synchronization switch will cause this item to stop uploading to the cloud. If turned on, it will synchronize the previous cloud configuration of this item to the local.
- If the automatic synchronization button is turned off, all cloud configurations will be retained until the last local configuration uploaded to the cloud before the synchronization is turned off.
- If the automatic synchronization button is enabled, the cloud configuration will be downloaded and synchronized locally.
- A separate switch has a similar effect to an automatic synchronization button, but the synchronization effect range has changed to the synchronization effect of the current item.
