# Markdown 语法示例

这是一份包含常用 Markdown 语法的示例文档，可用于测试编辑器或转换器的兼容性。

## 1. 标题（Headings）

使用 `#` 符号表示标题，`#` 数量对应标题级别（1-6级）：

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

## 2. 文本格式（Text Formatting）

- **加粗**：使用 `**文本**` 或 `__文本__` → **这是加粗文本**
- *斜体*：使用 `*文本*` 或 `_文本_` → *这是斜体文本*
- ***加粗+斜体***：使用 `***文本***` → ***这是加粗斜体文本***
- ~~删除线~~：使用 `~~文本~~` → ~~这是删除线文本~~
- `行内代码`：使用 `` `代码` `` → `print("Hello Markdown")`

## 3. 列表（Lists）

### 3.1 无序列表（Unordered Lists）
使用 `-`、`+` 或 `*` 作为前缀：
- 列表项 1
- 列表项 2
  - 子列表项 2.1（缩进 2 个空格）
  - 子列表项 2.2
- 列表项 3

### 3.2 有序列表（Ordered Lists）
使用 `数字.` 作为前缀：
1. 第一步
2. 第二步
   1. 子步骤 2.1
   2. 子步骤 2.2
3. 第三步

## 4. 链接与图片（Links & Images）

### 4.1 链接（Links）
格式：`[链接文本](URL "可选标题")`
- 普通链接：[GitHub](https://github.com "GitHub官网")
- 内部锚点：跳转到[标题部分](#1-标题headings)

### 4.2 图片（Images）
格式：`![替代文本](图片URL "可选标题")`
- 网络图片：
  ![Markdown Logo](https://markdown-here.com/img/icon256.png "Markdown Logo")
- 本地图片（相对路径）：
  ![本地示例图片](./images/example.png)
