# Camera
## Overview

The camera is a camera tool that comes with the system. It provides two shooting modes, namely, camera and video recording. It supports the functions of setting continuous shooting, delayed shooting, mirror flip shooting, and grid line shooting.

-"Taskbar">"Search"![](./image/search.png)>"Camera"<img src="./image/kylin-camera.png" style="zoom: 44.44%;"/>

## Basic operation

Select "![](./image/takephoto.png)" to open the camera mode. Click the capture button to obtain the current photo displayed by the camera and save it to the default storage path. The camera mode supports continuous shooting, delayed shooting, mirror shooting and grid reference line setting. The corresponding function description is shown in the table.

![](./image/main-english.png)

Photo mode function description

|Icon | Name | Description|
| ---------------------- | ------ | -------------- |
| ![](./image/picture5.png) | Serial shoot | Take multiple pictures in succession|
| ![](./image/picture6.png) | Delay | Delay shooting|
| ![](./image/picture7.png) | Mirror | Mirror shooting|
| ![](./image/picture8.png) | Grid | Set gridline shooting|

Select "![](./image/video-english.png)" to switch to the recording mode, click the shooting button to start recording, click "![](./image/picture10.png)" to pause recording, click "![](./image/picture11.png)" to continue recording, and click "![](./image/picture12.png)" to end recording. After recording, the recording file will be automatically saved to the default storage path.

![](./image/record.png)

Function description of video recording mode

|Icon | Name | Description|
| ---------------------- | ------ | -------------- |
| ![](./image/picture6.png) | Delay | Delay shooting|
| ![](./image/picture8.png) | Grid | Set gridline shooting|

Click "![](./image/setting.png)" to open the camera menu bar. Click **Set** to open the camera setting window, where you can set the default storage path, default camera, photo format, video format, and shooting resolution of the captured photos or videos. Click **Help** to automatically jump to the user manual, click **About** to view the current version information, and click **Quit** to exit the application.
