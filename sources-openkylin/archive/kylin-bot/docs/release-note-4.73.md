按提交日志看，upstream..feat/done-rebase 主要加了这些功能：

  产品化与打包

  - kylin-bot 的 Debian 打包资源和安装路径适配
  - 打包时把后端二进制一起带上
  - 构建脚本 build.sh 和相关 Linux/AppImage 构建流程
  - 桌面端启动时自动安装 rustls crypto provider，避免 reqwest 启动崩溃

  桌面端运行方式

  - 启动时自动拉起后端，退出时自动关闭后端
  - 曾去掉托盘，后面又重新加入托盘显示
  - 支持隐藏窗口和直接退出

  模型管理 / 试用账号

  - 接入试用账号
  - 统一维护“试用模型 + 已配置模型”列表
  - 增加模型配置页、模型配置引导
  - 支持添加模型、删除模型、编辑模型、查看模型
  - 聊天页当前模型持久化
  - 修复试用账号不生效、模型切换后不生效、custom 类型模型不可用等问题
  - 修正流式计费与试用模型价格

  身份与 Agent 配置

  - 支持设置 agent 用户名和角色，并写回配置
  - 修复“设置名字后回答内容不生效”

  技能系统

  - 技能列表从后端读取
  - 支持 skill 开关激活
  - 添加技能页面
  - 新增/调整多类 skills：
      - 学习 skill
      - 出差 skill
      - 安全 skill
      - 音乐控制相关能力与 kacp skills
  - 处理技能页无法加载 kacp skill
  - 调整安全配置，解决调用 skill 时安全策略限制问题

  - 历史会话切换流程
  - 回答中切换会话/新建会话时的提示弹窗
  - 实现停止回答 UI 和功能
  - 新增附件功能
  - 实时渲染 markdown

  设置与信息架构

  - 设置页重构，去掉无用页面，新增“常规”页面
  - 增加模型配置页、技能页
  - 左侧导航栏、标题栏、设置页整体 UI 调整
  - 侧边导航栏三态、悬浮态和样式优化

  新增业务页面

  - 流量统计页面
  - 记忆页面
  - 定时任务页面及控制接口

  UI / 品牌 / 视觉

  - 修改软件中英文名称
  - 更新图标、助手名字、欢迎文案
  - 首页、设置页、标题栏、发送按钮、置顶图标等大量 UI 调整
  - 默认浅色、隐藏部分菜单和置顶开关
  - 多次主页 UI 修复与样式优化
  - 鼠标悬浮时指针样式修正

  网关 / 协议侧

  - WebSocket 附件支持依赖补齐
  - runtime skills loader 接入
  - 停止回答、模型切换、身份设置等 WS 能力
  - 定时任务页面对应的 API / 控制接口
