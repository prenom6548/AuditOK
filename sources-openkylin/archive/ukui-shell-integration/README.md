# ukui-shell-integration

Ukui-shell-integration is a qtwayland plugin which can ensure your qt windows behaves identically on the UKUI platform as it does on Windows or X11.

## Build Dependencies
* cmake
* g++
* libwayland-dev
* qtbase5-private-dev
* qtwayland5-private-dev

You can install build-depends with follow command:
``` bash
sudo apt install cmake g++ libwayland-dev qtbase5-private-dev qtwayland5-private-dev
```
