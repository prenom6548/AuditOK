# Video Player
## Summary
Video Player is an audio and video player with beautiful interface and good interactivity,which support for .mkv, .avi, .mp4, .mp3, .wmv and other mainstream audio and video formats and have powerful decoding capabilities; complete functions, support playback order setting, screenshot, subtitle loading, screen settings, add file marks, incognito playback, etc. There are also Mini modes to meet different playback needs.

## Basic Operation

<br>

### Playback Page

After opening the Video Player, click "Open file" or "Open Directory" or press the key combination "Ctrl" + "O"/" Ctrl "+" F "to open the file or directory. After selecting the audio and video file, you can directly play it and add the file to the scalable playlist on the right. Double-click the playback interface to enlarge the window to full-screen playback, and double-click again to exit full-screen playback. When the cursor does not stop on the playback screen, the screen is simple and only the video playback window is kept.<br>
![Picture 2 Playback screen-Cursor does not pause-big](image/2.png)

<br>

When the cursor is on the video player screen, the file name of the current file is displayed, and the player bar, playlist button, and operation bar are called.<br>
The operation bar is displayed at the top of the interface. You can open the menu bar, enable the mini mode, minimize/maximize the window, and close the application.<br>
The Playbar is suspended at the bottom of the interface. You can perform the following operations: start/pause/switch the video, select the playback progress, set the speed, adjust the volume, take a screenshot, add a mark, and set the full screen. For detailed function descriptions, see the Playbar function description table.<br>
![Picture 3 Playback screen-Cursor stays-big](image/3.png)

<br>

Right-click in the playing interface to open the right-click menu bar of the playing interface, you can choose to open files, open directory, open URL, pin to top, you can set the playing order (single loop, list loop, random play), screen (clockwise/counterclockwise rotation 90°, horizontal/vertical flip, screen restoration, display introduction), Sound (tracks, channels, audio Settings), subtitles (load subtitles, subtitle selection, subtitle Settings), playback (play/pause, raise/lower volume, fast forward/rewind), open player Settings and view media information.<br>
![Picture 4 Play interface right-click menu bar-big](image/4.png)

### Play List

Click the button on the right of the playlist to expand the playlist. In the playlist, the "Video" screen displays the added audio and video files, and the "Marks" page displays the marked files. Double-click any file in the playlist to start playing. Click "![](image/icon22.png)" in the playlist to add files, click"![](image/icon14.png)"to clear all files in the list, select any file in the playlist, click" × "to the right of the file to delete the file in the list.<br>
The playlist can be played in Single loop, List Loop, or Random. Select the corresponding icon to switch between them: “![](image/icon15.png)”，“![](image/icon16.png)”，“![](image/icon17.png)”。<br>
The playlist also provides two view modes: list view and thumbnail view. The ICONS at the top of the playlist are respectively “![](image/icon18.png)” and “![](image/icon19.png)”.<br>
![Picture 6 Playlist-List view-big](image/6.png)
![Picture 7 Playlist-Thumbnail view-big](image/7.png)

<br>

Right-click any file in the playlist to open the right-click menu bar of the playlist. You can choose to remove selected items, remove invalid files, empty the playlist, and open the folder where the files are located.<br>
