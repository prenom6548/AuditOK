# 桌面小插件设计

## 配置文件
### 静态配置文件
静态配置是插件在桌面的固定配置，存放在插件的metadata.json文件中，桌面加载小插件时会读取metadata.json文件中的配置信息，初始化这些静态配置。

当前计划支持的静态配置有：
- Layer - 插件的层级，有-1、0、1三个层级，分别对应位于桌面图标下方、和桌面图标并存以及位于桌面图标上方；对于0层级，插件的布局会抢占桌面图标的位置，对于-1层级和1层级的插件，则会浮动在桌面图标的上方或下方。
- Anchors - 插件相对于桌面的锚点，数据是一个六元数组，每个元素是一个锚点配置对象。顺序分别为左、中、右、上、中、下。每个元素可以取的值为[0, 6]，0表示不启用，1-6分别对应桌面图标布局的anchors类型，同样按照左中右上中下的顺序排列。
- - 此配置和qtquick的配置实现有一定区别，在进行绑定时建议不要做太混乱的绑定，比如说把插件底部绑定到桌面顶部，插件顶部绑定到桌面底部这种配置，这样可能导致桌面插件显示异常，推荐对边角区域进行绑定配置，另外Anchors尽量避免和Dragable、Resizable同时配置，避免桌面逻辑出现问题
- SizePolicy - 插件计算大小和存储的方式，有两种方式对应0和1两种配置：1. 根据width和height计算和存储大小；2. 根据桌面网格计算和存储大小。
- SizeHint - 插件的大小，数据是一个二元数组，第一个元素表示宽度/横向网格占用，第二个元素表示高度/纵向网格占用。注意SizeHint给出的值相当于缺省值，实际大小可能会被动态配置覆盖。
- ManagerVariants / previewSize（可选）- 仅用于**插件管理器**里卡片预览的 `QQuickWidget` 像素尺寸。
- ManagerVariants / desktopSize（可选）- `[宽, 高]` 像素。通过管理器添加或拖放创建实例时，Peony 会写入该实例的 `width` / `height`，`widgets-proxy-model::itemSize` 优先采用，用于与 `previewSize` 不同的桌面实际显示尺寸。未配置时桌面仍按 `SizeHint` + 网格等规则换算。
- **ShowInManager**（可选，写在 `metadata.json` 的 `Contents` 内）- 设为 `true` 时，该插件才会出现在 Peony「桌面小插件管理」左侧分类与右侧预览网格中；未配置或为 `false` 时**不会**在管理器中列出（仍可被桌面其它路径加载，如已有配置）。兼容旧字段 **ManagerVisible**，二者任一为 `true` 即可。
- Dragable - 插件是否可拖动，取值为true或false。
- Resizable - 插件是否可缩放，取值为true或false。
- DoDecoration - 插件是否需要进行装饰，取值为true或false。
- DoBlur - 插件是否需要模糊背景，取值为true或false。

### 动态配置文件
动态配置文件是插件在运行时动态生成的配置文件，用于保存插件的运行时配置信息，动态配置的信息存储在ukui-quick插件对应的config中，遵循ukui-quick配置规则，这里不考虑插件自身写配置的情况，只考虑桌面小插件框架相关的动态配置。当前计划支持的动态配置有：

- Position - 插件的位置，数据是一个二元数组，第一个元素表示横向坐标/网格位置，第二个元素表示纵向坐标/网格位置。
- Size - 插件的大小，数据是一个二元数组，第一个元素表示宽度/横向网格占用，第二个元素表示高度/纵向网格占用。

### 其它配置
由于ukui-quick插件框架对于插件在不同island下的管理功能没有约束和规范，桌面为了适配小插件在多屏下的管理，还需要在桌面本身配置中增加小插件所在island的配置，当前桌面island的配置和screenid关联，这里需要将小插件实例转化为唯一id，再和screenid进行关联，以实现小插件的多屏管理。
