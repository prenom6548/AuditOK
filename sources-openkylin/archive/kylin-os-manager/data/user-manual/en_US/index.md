# Kylin Os Manager

## Summary

Kylin os manager is an application that provides problem feedback, offline FAQ, computer troubleshooting, troubleshooting, computer garbage cleaning, device management, and system tools, which can help you better use your computer.

## Open mode

Click the "**Start Menu**" of the operating system, select and click "**kylin os manager**".

## Basic operation

### Home page

The home page of kylin os manager displays the system health and computer junk situation, which can be repaired and cleared by clicking the corresponding button. At the same time, it provides quick access to the computer treasure box and self-service solutions for faults, which can be easily redirected to the corresponding interface.

![Figure 1 Home Page Interface-big](image/1.png)

### Fault detection

Click "**Start**" in "**Fault detection**" to start detection.

![Figure 2 Fault Detection Interface-big](image/2.png)

![Figure 3 Detection Interface-big](image/3.png)

After the detection is completed, the detection result will be displayed.

![Figure 4 Test Result Interface-big](image/4.png)

Kylin os manager also supports internal network detection. Click on "Internal Network Detection Settings" in the bottom right corner and select "Yes" to enable internal network detection and configure IP and website addresses for saving.

![Figure 5 Intranet Detection Configuration Interface-big](image/5.png)

### Junk Clean

Kylin os manager supports cleaning system junk, internet junk, and historical traces. Click "**Start Scanning**" to start scanning.

![Figure 6 Garbage Cleaning Interface-big](image/6.png)

After the scan is completed, the scan items and cleanable items will be displayed. Click the dropdown button on the right to view the specific cleanable items. Click "**One click cleaning**" to start cleaning.

![Figure 7 Scan Completion Interface-big](image/7.png)

![Figure 8 Cleaning Completion Interface-big](image/8.png)

### Device Manager

Device management is used to query and manage hardware devices, including viewing and exporting hardware information, enabling and disabling devices, as well as driver management functions. It can also install, upgrade, and uninstall external device drivers.

### Treasure chest

The Gallery is used to store all kinds of small tools. Click the interface of the corresponding tool to start the small tools.

![Figure 19 Gallery Interface-big](image/19.png)

### Kylin File Crush

A file shredder is a tool designed to completely erase files from a disk and make them unrecoverable. Its main design purpose is to protect sensitive data from malicious theft and exploitation. The file shredder uses advanced algorithms and techniques to ensure that files are overwritten and unrecoverable.

After opening the file shredder, you can click the "+" button in the middle of the interface or the "Add" button in the bottom left corner to add files or folders, and it also supports drag and drop addition.

![Figure 20 File Crush Interface-big](image/20.png)

After adding, if you want to remove certain items, you can check the checkbox at the front and click the "Remove" button below.

![Figure 21 File Crush Removal Interface-big](image/21.png)

Check the items that need to be crushed, click the "Crush" button in the bottom right corner, and a pop-up window will appear to confirm whether to crush them. Click the "OK" button to crush the file.

![Figure 22 File Crush Confirmation Interface-big](image/22.png)

### Network Connectivity Detection Tools

Network connectivity detection tools can quickly detect whether the network is unobstructed, helping you easily grasp the network status.

Open the network connectivity testing tool, enter the IP or domain name, port number that needs to be tested, and click the test button in the bottom right corner.

![Figure 23 NetWork Connectivity Detection Tools Interface-big](image/23.png)

If the network is unobstructed, a pop-up window will display a successful connection.

![Figure 24 Connection successful-big](image/24.png)

If the network is not connected, a pop-up window will display connection failure.

![Figure 25 connection failed-big](image/25.png)

### D-Feet

D-Feet is a powerful graphical tool designed specifically for D-Bus system services on the Linux platform. It allows users to browse the D-Bus interface on the system and session bus, view and call methods, signals, properties, etc. D-Feet provides an intuitive user interface that enables developers and system administrators to easily debug and test D-Bus services.

After startup, D-Feet will automatically connect to the system bus and session bus, and can be switched by pressing the button above to view the currently active D-Bus services.

![Figure 26 D-Feet Interface-big](image/26.png)

Find the corresponding service through the search box, click on the service, and its interface and object path will be displayed in the right panel.

![Figure 27 Show The Interface And Object Path Interface-big](image/27.png)

Clicking on a specific interface will list the methods, signals, and properties provided by that interface.

![Figure 28 Show The Methods, Signals And Properties Under The Interface-big](image/28.png)

Select a method by entering the necessary parameters and clicking the 'Run' button to execute the method.

![Figure 29 Execution Method-big](image/29.png)

### Disk Usage Analyzer

Disk Usage Analyzer is a graphical disk usage analysis tool that helps users visualize the usage of disk space for easy identification and management of large files or folders.

After startup, you can choose the scanning range and directly scan the entire disk or select specific folders for analysis.

![Figure 30 Select Scanning Range-big](image/30.png)

After scanning is completed, a visual graph will be displayed showing the proportion of each directory.

![Figure 31 Scan Completion Interface-big](image/31.png)

Clicking on any part of the chart allows for a deeper view of the size of subdirectories and files.
