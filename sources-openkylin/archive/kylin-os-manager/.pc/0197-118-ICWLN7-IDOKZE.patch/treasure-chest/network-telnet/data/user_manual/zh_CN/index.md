# 网络连通性检测工具

## 概述

网络连通性检测工具可以快速检测网络是否通畅，帮助您轻松掌握网络状态。

## 打开方式

点击操作系统“开始菜单”，选择并点击“麒麟管家” -> “百宝箱” -> “网络连通性检测工具” 。

## 基本操作

打开网络连通性检测工具，输入需要检测的 IP 或域名、端口号后，点击右下角测试按钮。

![图 1 网络连通性检测工具界面-big](image/1.png)

如果网络通畅会弹窗显示连接成功。

![图 2 连接成功-big](image/2.png)

如果网络不通会弹窗显示连接失败。

![图 3 连接失败-big](image/3.png)
